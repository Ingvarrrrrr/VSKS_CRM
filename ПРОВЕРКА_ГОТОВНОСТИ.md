## Быстрая диагностика

### Если меню не появляется:

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `onOpen`
3. Запустите ее вручную (кнопка ▶)
4. Вернитесь в Google Sheets
5. Меню должно появиться

### Если GUI не открывается:

1. Проверьте, что функция `showFileSelectionDialog` есть в коде
2. Проверьте логи выполнения на ошибки
3. Убедитесь, что проект сохранен

### Если файлы не находятся:

1. Убедитесь, что файл "Патриотика" существует в Google Sheets
2. Проверьте права доступа к файлу
3. Используйте поиск в диалоговом окне

## Код для быстрой проверки

Добавьте эту функцию в Apps Script для тестирования:

```javascript
function testMenu() {
  // Принудительно создаем меню
  onOpen();
  
  // Проверяем доступные файлы
  var files = getAvailableFiles();
  Logger.log('Найдено файлов: ' + files.length);
  files.forEach(function(file) {
    Logger.log('- ' + file.name + ' (ID: ' + file.id + ')');
  });
  
  SpreadsheetApp.getUi().alert(
    'Тест завершен',
    'Найдено файлов: ' + files.length + '\nПроверьте логи выполнения',
    SpreadsheetApp.getUi().ButtonSet.OK
  );
}
```

Запустите `testMenu()` для диагностики.
