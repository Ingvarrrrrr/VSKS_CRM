# CRM Система - Локальное приложение

Полнофункциональная CRM система для управления договорами, контрагентами и субсидиями с графическим интерфейсом.

## Возможности

- ✅ **Управление договорами** - создание, редактирование, просмотр договоров со всеми параметрами
- ✅ **Управление контрагентами** - база данных контрагентов с автозаполнением реквизитов
- ✅ **Категоризация по ФЭО** - выбор категорий через чекбоксы (галочки)
- ✅ **Состав договора** - добавление позиций товаров/услуг
- ✅ **Финансовые расчеты** - автоматический расчет НДС, экономии, остатков
- ✅ **Импорт данных** - импорт из исходного файла "Патриотика"
- ✅ **Красивый интерфейс** - современный GUI на PyQt6
- ✅ **Локальная работа** - все данные хранятся в Excel файле

## Установка

### Требования

- Python 3.8 или выше
- pip (менеджер пакетов Python)

### Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 2: Создание структуры базы данных

```bash
python create_excel_structure.py
```

Это создаст файл `CRM_База_Данных.xlsx` со всеми необходимыми листами.

### Шаг 3: Импорт данных (опционально)

Если у вас есть исходный файл "Патриотика 2025 (5).xlsx":

```bash
python import_data.py "путь/к/файлу/Патриотика 2025 (5).xlsx"
```

### Шаг 4: Запуск приложения

```bash
python main.py
```

## Использование

### Работа с договорами

1. Откройте вкладку **"📄 Договоры"**
2. Заполните основную информацию:
   - Номер договора
   - Дата договора
   - Тип и вид договора
   - Субсидия
   - Контрагент (или добавьте нового)
3. Добавьте позиции в состав договора (кнопка "➕ Добавить позицию")
4. Заполните финансовые условия
5. Выберите категории ФЭО через **чекбоксы (галочки)**
6. Нажмите **"💾 Сохранить договор"**

### Работа с контрагентами

1. Откройте вкладку **"👥 Контрагенты"**
2. Нажмите **"➕ Добавить контрагента"**
3. Заполните обязательные поля (Контрагент, ИНН)
4. Заполните дополнительные реквизиты
5. Нажмите **"OK"**

### Выбор категорий ФЭО

Категории выбираются через **чекбоксы (галочки)**:

1. В разделе "Категоризация по ФЭО" выберите нужные категории
2. Можно выбрать несколько категорий одновременно
3. После выбора категорий ФЭО автоматически обновится список типов расходов
4. Аналогично для категорий из приложения

## Структура базы данных

База данных хранится в файле `CRM_База_Данных.xlsx` и содержит следующие листы:

- **GoodsService** - основная таблица договоров
- **Состав_договора** - позиции товаров/услуг по договорам
- **Контрагенты** - база данных контрагентов
- **Субсидии** - справочник субсидий
- **Категории_из_ФЭО** - категории ФЭО с подкатегориями
- **Категории_из_приложения** - категории из приложений к ФЭО
- **Платежи** - платежи по договорам
- **Документы** - документы по договорам
- **Дашборд** - аналитический дашборд
- **Реестр_договоров** - реестр всех договоров
