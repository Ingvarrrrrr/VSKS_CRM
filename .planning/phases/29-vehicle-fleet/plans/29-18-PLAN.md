## Tasks

**Task 1: VehicleAttachmentSlot.vue (~120 LOC)** — переиспользуемый компонент для одного слота. Props: `vehicleId`, `kind` ('sts'/'pts'/'osago'/'kasko'/'dk'/'permit_to'), `label`, `requireMetadata: boolean` (true для osago/kasko/dk). Если file загружен: показать имя + кнопку «Скачать» + «Удалить»; для image — preview thumbnail; для osago/kasko/dk — поля policy_number/issued_at/expires_at inline (PATCH `/api/vehicle-attachments/{id}`). Если файл нет: FileDropZone (existing component) + POST `/api/vehicle-attachments/upload` с kind. Lookup attachment по `GET /api/vehicle-attachments?vehicle_id=X&kind=Y` (берёт ПЕРВЫЙ).

**Task 2: VehicleDocumentsTab.vue (~150 LOC)** — 6 VehicleAttachmentSlot (СТС/ПТС/ОСАГО/КАСКО/ДК/Разрешение ТО) + раздел «Прочее»: list `GET /api/vehicle-attachments?vehicle_id=X&kind=other` + кнопка «Добавить документ» (FileDropZone + name input).

**Task 3: VehiclePhotosTab.vue (~150 LOC)** — `v-row` с `v-col` для каждой фотки. Grid thumbnails (3-4 в ряд). Click → v-dialog с full-size preview. FileDropZone для upload (kind='photo'). Delete confirmation. GET `/api/vehicle-attachments?vehicle_id=X&kind=photo`.

**Task 4: RepairsTab.vue (~250 LOC)** — timeline-вид:
- Кнопка «Добавить ремонт» вверху → диалог с полями (date, description, cost_amount, performed_by_name, mileage_at_repair, status, purchase_id (v-autocomplete по purchases))
- `v-timeline` с записями ремонтов (newest сверху)
- Каждая запись — `v-timeline-item` с expand-on-click показывает: full description, status chip, cost, mileage, linked Purchase (если есть — link на `/purchases/${id}`), RepairAttachments grid (с upload+download+delete для kind='order_form'/'act'/'invoice'/'photo'/'other')
- `GET /api/vehicle-repairs?vehicle_id=X` для load
- inline-edit для status (v-select) с PATCH

**Task 5: OdometerTab.vue (~200 LOC)** — inline-edit таблица (PurchaseItemsEditor pattern from PATTERNS):
- Columns: Дата | Одометр км | Delta км (readonly, computed на backend) | Топливо л (readonly) | Источник | Заметка | Действия
- Row create на верху (или нижняя строка с placeholder «+ добавить»). При save → POST `/api/vehicle-odometer`
- Inline-edit `note` через v-text-field, save on blur → PATCH
- Delete row с confirmation
- Sort: date DESC
- monotonic violation 422 → snackbar с конкретным сообщением «Одометр не может уменьшаться (последнее значение: X км)»

**Task 6: FuelLogTab.vue (~200 LOC)** — inline-edit таблица:
- Columns: Дата | Литры | Цена/л | Сумма (auto: liters*price если не задано) | Тип топлива | Чек | Действия
- POST `/api/fuel-logs` для новой записи
- При вводе price_per_liter — auto-fetch latest-price от `/api/fuel-logs/latest-price/{vehicleId}` при focus поля (для удобства)
- receipt_attachment_id — выбор из существующих VehicleAttachment с kind='other' (фильтр по имени `чек*`) ИЛИ кнопка «Загрузить чек» (создаст attachment с kind='other', name=`Чек {date}`)
- Sort: date DESC

**Task 7: TripsTab.vue (~250 LOC)** — список путёвок + create form:
- `v-data-table` с колонками: Дата | Водитель | Маршрут | Одометр (start → finish) | Статус | Действия
- Кнопка «Создать путёвку» → v-dialog с полями:
  - `date` (default today)
  - **Driver selector:** v-autocomplete с items из `GET /api/drivers/available?org_id=${vehicle.owner_org_id}` (union User+ExternalDriver). При выборе ExternalDriver — показывать «внешний:» префикс. Кнопка «Добавить внешнего водителя» → mini-dialog → POST `/api/external-drivers` → re-fetch /available.
  - `route_from`, `route_to` v-text-field (autocomplete from `/api/trips/route-suggestions?q=...` — это в RESEARCH R-11)
  - `purpose` v-textarea
  - `odometer_start` (default = vehicle.current_odometer_km), `odometer_finish`
  - Truck-only поля (показывать если vehicle.type ∈ truck_*): cargo_name, cargo_weight_t, loading_point, unloading_point
  - Fuel: fuel_remaining_start, fuel_remaining_finish, fuel_issued_l
- POST `/api/trips` → success → snackbar
- **Кнопка «Сгенерировать .docx»** в каждой строке списка → POST `/api/trips/{id}/render` → download file. При 500 → диалог с err.code/error_raw/traceback + кнопка «Скопировать» (Lesson 2026-05-14).

**Task 8: RelatedPurchasesTab.vue (~150 LOC)** — `GET /api/purchases?vehicle_id=${id}` (новый query-param на existing endpoint; если нет — добавить в backend? **Уточнение:** этот param добавляется в **плане 29-21**, либо здесь как inline modification of purchases.py — выбрать здесь, чтобы зависимость была локализована в 29-21). Группировка списка по типу закупки (ремонт / топливо / страхование / прочее — по subject keywords). Total per group. Каждая строка — link на `/purchases/${id}`.
