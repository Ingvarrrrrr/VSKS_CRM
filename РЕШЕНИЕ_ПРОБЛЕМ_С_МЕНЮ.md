# Решение проблем с меню и импортом данных

## Проблема: Меню "Импорт данных" не появляется

### Решение 1: Принудительное создание меню

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `createMenu` (или добавьте её, если нет)
3. Выберите функцию `createMenu`
4. Нажмите **Выполнить** (▶)
5. Вернитесь в Google Sheets
6. Меню должно появиться

### Решение 2: Обновление страницы

1. После создания структуры обновите страницу Google Sheets (F5)
2. Меню должно появиться автоматически

### Решение 3: Проверка функции onOpen

Убедитесь, что в коде есть функция `onOpen()`:

```javascript
function onOpen() {
  createMenu();
}

function createMenu() {
  var ui = SpreadsheetApp.getUi();
  ui.createMenu('📥 Импорт данных')
    .addItem('📂 Импорт из Google Sheets файла', 'showFileSelectionDialog')
    .addSeparator()
    .addItem('📄 Импорт из текущего файла', 'importFromCurrentFile')
    .addSeparator()
    .addItem('🔄 Обновить меню', 'createMenu')
    .addToUi();
}
```

## Проблема: Данные не импортируются

### Решение 1: Проверка структуры

Убедитесь, что структура создана:
- [ ] Есть лист "Субсидии"
- [ ] Есть лист "Категории_из_ФЭО"
- [ ] Есть лист "Категории_из_приложения"
- [ ] Есть лист "Контрагенты"

### Решение 2: Ручной запуск импорта

Если GUI не работает, можно импортировать данные вручную:

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `importFromCurrentFile`
3. Запустите её (▶)
4. Данные будут импортированы из текущего файла

### Решение 3: Проверка исходного файла

Убедитесь, что файл "Патриотика" содержит нужные листы:
- Лист "GoodsService" - для импорта субсидий и контрагентов
- Лист "Категории_из_ФЭО" - для импорта категорий ФЭО
- Лист "Категории_из_приложения" - для импорта категорий из приложения

## Быстрое решение: Функция для тестирования

Добавьте эту функцию в Apps Script для диагностики:

```javascript
function testAndFix() {
  // 1. Создаем меню
  createMenu();
  
  // 2. Проверяем структуру
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var requiredSheets = [
    'GoodsService', 'Состав_договора', 'Контрагенты', 'Субсидии',
    'Категории_из_ФЭО', 'Категории_из_приложения', 'Платежи',
    'Документы', 'Дашборд', 'Реестр_договоров'
  ];
  
  var missingSheets = [];
  requiredSheets.forEach(function(sheetName) {
    if (!ss.getSheetByName(sheetName)) {
      missingSheets.push(sheetName);
    }
  });
  
  // 3. Проверяем доступные файлы
  var files = getAvailableFiles();
  
  // 4. Выводим результаты
  var message = 'Диагностика:\n\n';
  message += 'Листы: ' + (requiredSheets.length - missingSheets.length) + ' из ' + requiredSheets.length + '\n';
  if (missingSheets.length > 0) {
    message += 'Отсутствуют: ' + missingSheets.join(', ') + '\n';
  }
  message += '\nНайдено файлов для импорта: ' + files.length + '\n';
  
  if (files.length > 0) {
    message += '\nФайлы:\n';
    files.slice(0, 5).forEach(function(file) {
      message += '- ' + file.name + '\n';
    });
  }
  
  SpreadsheetApp.getUi().alert('Диагностика', message, SpreadsheetApp.getUi().ButtonSet.OK);
  
  Logger.log('Диагностика завершена');
}
```

Запустите `testAndFix()` для проверки всех компонентов.

## Пошаговая инструкция исправления

### Шаг 1: Обновите скрипт

1. Откройте `ПОЛНЫЙ_СКРИПТ_БАЗЫ_ДАННЫХ.gs`
2. Убедитесь, что функция `createMenu()` есть в коде
3. Скопируйте обновленный код в Apps Script
4. Сохраните (Ctrl+S)

### Шаг 2: Создайте меню вручную

1. В Apps Script выберите функцию `createMenu`
2. Нажмите **Выполнить** (▶)
3. Вернитесь в Google Sheets
4. Меню должно появиться

### Шаг 3: Импортируйте данные

1. Нажмите **📥 Импорт данных → 📂 Импорт из Google Sheets файла**
2. Выберите файл "Патриотика"
3. Нажмите **Импортировать**
4. Проверьте результаты

### Шаг 4: Если импорт не работает

1. Попробуйте **📥 Импорт данных → 📄 Импорт из текущего файла**
2. Или запустите функцию `importFromCurrentFile()` вручную в Apps Script
