## Tasks
1. Создать `vehicle_repairs.py` с `router = APIRouter(prefix="/api/vehicle-repairs", tags=["vehicles"])`.
2. Импорты: `Vehicle, VehicleRepair, RepairAttachment, Purchase` (для FK validation), `get_org_filter`, `require_action`, `require_tab`, `_coerce_patch_value` (скопировать helper в файл или вынести в `app/auth/visibility.py`/`app/utils/patch.py` — выбрать **скопировать в файл** для скорости).
3. `_DATE_FIELDS = {"date"}`, `_DATETIME_FIELDS = set()`.
4. `_visibility_check(repair, user)` — берёт `repair.vehicle.owner_org_id` или `assigned_org_id`, сравнивает с `get_org_filter(user)`. Если не admin и нет пересечения → 403.
5. `GET /api/vehicle-repairs?vehicle_id={id}&status=&date_from=&date_to=` — список ремонтов. require_tab('vehicles') + visibility (через vehicle_id). ORDER BY `date DESC`. Joined load на `attachments` (selectinload). Возвращает `List[RepairOut]`.
6. `GET /api/vehicle-repairs/{repair_id}` — один ремонт с attachments. require_tab + visibility.
7. `POST /api/vehicle-repairs` — create. `require_action('vehicle.repair.write')`. Body: `{vehicle_id, date, description, cost_amount, performed_by_name, mileage_at_repair, status, purchase_id}`. Если `purchase_id` передан — `select(Purchase).where(id=purchase_id)` → если не найден, 422 `{code:'INVALID_PURCHASE_ID',...}`. created_by_id = current_user.id. Возвращает `RepairOut`.
8. `PATCH /api/vehicle-repairs/{repair_id}` — partial update. `_coerce_patch_value`. require_action + visibility.
9. `DELETE /api/vehicle-repairs/{repair_id}` — `require_action('vehicle.delete')` (используем тот же action, не нужен отдельный). CASCADE удалит repair_attachments по FK.
10. **Двусторонняя ссылка с Purchase:** добавить вспомогательный endpoint `GET /api/purchases/{purchase_id}/repair-link` — возвращает `{repair_id, vehicle_id}` если есть VehicleRepair с этим purchase_id. Использовать на фронте для показа cross-link.
11. В `__init__.py` `include_router(vehicle_repairs.router)` после vehicles.router.
12. Commit message: `feat(29-06): backend router vehicle_repairs — CRUD + Purchase FK`
