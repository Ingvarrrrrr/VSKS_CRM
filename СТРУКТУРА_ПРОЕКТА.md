## Структура Google Sheets

### Лист: GoodsService
**Назначение:** Основная таблица с данными договоров

**Столбцы (примерная структура):**
- A: Номер закупки
- B: Номер заказа внутри закупки
- C: Предмет договора
- D: Наименование товара
- E: Контрагент
- F: Плановое количество
- G: Ед. изм. (ОКЕИ)
- H: Плановая стоимость за единицу
- I: Итоговая цена за единицу
- J: Субсидия
- K: Статус договора
- L: Стадия исполнения
- M: Плановая дата поставки
- N: Общая сумма
- O: Законтрактовано
- P: Поставлено
- Q: Оплачено
- ... (все остальные столбцы из исходного файла)
- AF (30): Направление расходов по категориям ФЭО
- AG (31): Тип расходов в соответствии с ФЭО
- AH (32): Направление расходов из приложений к ФЭО
- AI (33): Тип расходов конкретизированный

**Форматирование:**
- Условное форматирование по статусам
- Защита формул
- Замороженная первая строка

### Лист: Контрагенты_список
**Назначение:** Список всех контрагентов с полными реквизитами

**Столбцы:**
- A: Контрагент
- B: ФИО РУКОВОДИТЕЛЯ
- C: Должность руководителя
- D: Основание на котором действует
- E: Полное наименование
- F: ИНН
- G: КПП
- H: Расчётный счёт
- I: Кореспондентский счёт
- J: БИК банка
- K: Юридический адрес
- L: Фактический адрес
- M: Телефон организации
- N: E-mail
- O: Контактное лицо
- P: Телефон контактного лица

### Лист: Категории_из_ФЭО
**Назначение:** Структура категорий ФЭО с зависимостями

**Структура:**
- Первая строка: названия категорий
- Последующие строки: подкатегории

### Лист: Категории_из_приложения
**Назначение:** Структура категорий из приложений к ФЭО

**Структура:**
- Аналогично Категории_из_ФЭО

### Лист: Субсидии
**Назначение:** Список субсидий

**Столбцы:**
- A: Название субсидии
- B: Общий объём
- C: Год
- D: Ведомство

### Лист: Дашборд
**Назначение:** Интерактивный дашборд с метриками

**Структура:**
- Метрики по каждой субсидии
- Графики
- Фильтры

### Лист: Реестр_договоров
**Назначение:** Сводная информация о договорах

**Столбцы:**
- A: Номер договора
- B: Контрагент
- C: Предмет договора
- D: Сумма договора
- E: Законтрактовано
- F: Поставлено
- G: Оплачено
- H: Статус
- I: Стадия исполнения

### Лист: Платежи
**Назначение:** История платежей

**Столбцы:**
- A: Дата платежа
- B: Номер платежа
- C: Контрагент
- D: Сумма
- E: Договор
- F: Статус сверки

## Порядок реализации

1. **Создать структуру Google Sheets**
   - Создать все необходимые листы
   - Настроить заголовки
   - Применить базовое форматирование

2. **Создать базовую структуру Google Apps Script**
   - Создать файлы .gs по категориям
   - Создать HTML формы
   - Настроить конфигурацию

3. **Реализовать функции по этапам**
   - Следовать плану реализации
   - Тестировать каждый этап

4. **Настроить шаблоны документов**
   - Загрузить шаблоны в Google Drive
   - Настроить плейсхолдеры
   - Протестировать генерацию

5. **Настроить права доступа**
   - Определить роли пользователей
   - Настроить права в Google Sheets
   - Протестировать доступ

## Рекомендации по разработке

1. **Версионирование**
   - Использовать Git для версионирования кода

4. **Оптимизация**
