В файле `backend/app/schemas/schemas.py` найти класс `PublishRequest` и добавить опциональное поле:

```python
from typing import Optional  # убедиться что импортирован

class PublishRequest(BaseModel):
    platform: str  # fabrikant / roseltorg_rb
    procedure_type: Optional[str] = None  # только для roseltorg_rb: request_quotations / request_proposals / competition / auction
```

Поле ОБЯЗАТЕЛЬНО опциональное (Optional[str] = None) — это обеспечивает обратную совместимость с существующими запросами к Фабрикант, которые не передают procedure_type.

ВАЖНО: не делать поле обязательным и не добавлять валидатор допустимых значений — значения templateId уточнятся позже при получении реального токена Росэлторг.
