```

POST   /api/wishes/{id}/submit               -> WishOut
```

**"Мои заявки" tab (all roles):**
- Fetch `GET /api/wishes?mine_only=true` on mount
- Show list of own wishes as `v-card` items with:
  - Title, description (truncated), quantity, unit, estimated_price
  - Status chip: draft=grey, submitted=blue, approved=green, rejected=red, converted=purple
  - If `status === 'rejected'`: show `rejection_reason` in red text
  - If `status === 'converted'` and `purchase_id`: show link `Перейти к закупке` -> `/orders/${purchase_id}/edit`
  - If `status === 'draft'`: show Edit and Submit buttons
  - If `status === 'draft'`: show Delete button (icon)
- FAB button (mdi-plus) to create new wish -> opens create dialog

**Create/Edit Wish Dialog (`v-dialog`):**
- Fields: title (required, v-text-field), description (v-textarea), quantity (v-text-field type=number), unit (v-text-field), estimated_price (v-text-field type=number), justification (v-textarea, label "Обоснование")
- Save: POST /api/wishes (create) or PUT /api/wishes/{id} (edit)
- After save, refresh list

**Submit action:**
- Inline button on draft wish card
- Calls `POST /api/wishes/{wish.id}/submit`
- After success, refresh list, show snackbar "Заявка отправлена"

**"Заявки сотрудников" tab (manager/admin only):**
- Fetch `GET /api/wishes?status=submitted` (default filter to show actionable wishes)
- Add filter chips: all, submitted, approved, rejected, converted
- Show list of wishes with:
  - Title, description, creator_name, quantity, unit, estimated_price, justification
  - Status chip
  - If `status === 'submitted'`: show "Одобрить" (green) and "Отклонить" (red) buttons
  - If `status === 'approved'` and user is in ADMIN_ROLES: show "Создать закупку" button

**Approve action:**
- Calls `POST /api/wishes/{wish.id}/approve`
- Refresh list, snackbar "Заявка одобрена"

**Reject action:**
- Opens reject dialog with `v-textarea` for rejection_reason (required)
- Calls `POST /api/wishes/{wish.id}/reject` with `{ rejection_reason }`
- Refresh list, snackbar "Заявка отклонена"

**Convert action (org_admin+):**
- Opens convert dialog with:
  - Read-only: original title, quantity, estimated_price from wish
  - Editable: approved_quantity (pre-filled from wish.quantity), approved_price (pre-filled from wish.estimated_price)
  - Optional: subsidy_id dropdown (fetch from `/api/subsidies` filtered by current org)
- Calls `POST /api/wishes/{wish.id}/convert` with `{ approved_quantity, approved_price, subsidy_id }`
- On success: snackbar "Закупка создана", navigate to `/orders/${response.purchase_id}/edit`
