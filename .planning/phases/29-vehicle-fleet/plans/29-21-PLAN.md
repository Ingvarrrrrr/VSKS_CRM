**Task 2: Frontend CreateOrderView.vue:**
1. Найти место в форме создания закупки где есть `subject` v-text-field.
2. Добавить **computed property:**
   ```typescript
   const VEHICLE_KEYWORDS = ['ремонт тс', 'ремонт автомобил', 'заправк', 'то ', 'тех. обслуж', 'техобслуж', 'страхован', 'запчаст', 'шиномонтаж', 'диагностик']
   const showVehicleSelect = computed(() => {
     const s = (form.value.subject || '').toLowerCase()
     return VEHICLE_KEYWORDS.some(kw => s.includes(kw))
   })
   ```
3. Добавить в форму **условное поле:**
   ```vue
   <v-expand-transition>
     <v-autocomplete
       v-if="showVehicleSelect"
       v-model="form.vehicle_id"
       :items="vehicleOptions"
       item-title="label"
       item-value="id"
       label="Автомобиль"
       prepend-inner-icon="mdi-car"
       clearable
       variant="outlined"
       density="compact"
       :loading="vehiclesLoading"
       @update:search="onVehicleSearch"
       class="mb-2"
     />
   </v-expand-transition>
   ```
4. **Загрузка vehicleOptions:**
   ```typescript
   const vehicleOptions = ref<any[]>([])
   const vehiclesLoading = ref(false)
   const vehicleSearchDebounce = ref<ReturnType<typeof setTimeout> | null>(null)
   async function loadVehicles(q: string = '') {
     vehiclesLoading.value = true
     try {
       const r = await apiFetch(`/api/vehicles?q=${encodeURIComponent(q)}&limit=30`)
       vehicleOptions.value = r.items.map((v: any) => ({
         id: v.id,
         label: `${v.brand} ${v.model} · ${v.plate}`,
       }))
     } finally { vehiclesLoading.value = false }
   }
   function onVehicleSearch(q: string) {
     if (vehicleSearchDebounce.value) clearTimeout(vehicleSearchDebounce.value)
     vehicleSearchDebounce.value = setTimeout(() => loadVehicles(q), 300)
   }
   // Initial load when select first shows
   watch(showVehicleSelect, (v) => { if (v && vehicleOptions.value.length === 0) loadVehicles() })
   ```
5. **Save POST:** включить `form.value.vehicle_id` в body — backend (Task 1) уже принимает.
6. **При редактировании существующей закупки:** если `purchase.vehicle_id` задан — preload в form. Если есть — селект показывается даже без keyword match (просто showVehicleSelect=true при наличии vehicle_id).
7. Уточнить watcher: `showVehicleSelect = computed(() => keywordMatch || !!form.value.vehicle_id)`.
8. Pre-push grep duplicate let/const.
