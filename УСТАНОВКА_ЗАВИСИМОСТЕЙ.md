# Установка зависимостей для CRM приложения

## Ошибка: ModuleNotFoundError: No module named 'PyQt6'

Эта ошибка означает, что модуль PyQt6 не установлен в вашей системе Python.

## Решение

### Вариант 1: Установка через pip (если Python установлен)

Откройте командную строку или PowerShell в папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
```

Или:

```bash
pip install -r requirements.txt
```

### Вариант 2: Если Python не найден

1. **Установите Python 3.8 или выше:**
   - Скачайте с официального сайта: https://www.python.org/downloads/
   - При установке **ОБЯЗАТЕЛЬНО** отметьте галочку "Add Python to PATH"
   - После установки перезапустите командную строку/PowerShell

2. **Проверьте установку:**
   ```bash
   python --version
   ```
   Должно показать версию Python (например, Python 3.11.0)

3. **Установите зависимости:**
   ```bash
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt
   ```

### Вариант 3: Использование виртуального окружения (рекомендуется)

1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

2. Активируйте его:
   - Windows (PowerShell):
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
   - Windows (CMD):
     ```cmd
     venv\Scripts\activate.bat
     ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Что устанавливается

Из файла `requirements.txt` будут установлены:

- **openpyxl** - для работы с Excel файлами
- **pandas** - для обработки данных
- **PyQt6** - для графического интерфейса
- **python-docx** - для работы с Word документами
- **xlrd** - для чтения старых Excel файлов

## Проверка установки

После установки проверьте:

```bash
python -c "import PyQt6; print('PyQt6 установлен успешно!')"
```

Если ошибок нет - все готово!

## Запуск приложения

После установки зависимостей запустите:

```bash
python main.py
```

Или используйте файл `run.bat` (он автоматически проверит зависимости).

## Если проблемы остаются

1. Убедитесь, что используете правильную версию Python (3.8+)
2. Попробуйте переустановить pip:
   ```bash
   python -m pip install --upgrade pip
   ```
3. Установите пакеты по одному:
   ```bash
   pip install openpyxl
   pip install pandas
   pip install PyQt6
   ```

## Альтернатива: Использование tkinter (встроенный в Python)

Если PyQt6 не устанавливается, можно переделать интерфейс на tkinter (встроен в Python):

- Не требует установки дополнительных библиотек
- Проще в использовании
- Менее современный внешний вид

Но для лучшего интерфейса рекомендуется использовать PyQt6.
