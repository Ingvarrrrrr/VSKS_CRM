2. **Loader:** `loadVehicles()` async — `apiFetch('/api/vehicles?' + querystring)`. Параметры: state, type, owner_org_id, assigned_org_id, q, limit=25, offset=page*25. После load: `items.value = data.items`, `total.value = data.total`.
3. **Create dialog** (минимальный): plate, brand, model, owner_org_id, type, state. POST `/api/vehicles`. Success → router.push(`/property/vehicles/${created.id}`).
4. **VehicleImportDialog.vue:**
   - Step 1: FileDropZone (existing component) → выбор .xlsx
   - Step 2: POST `/api/vehicles-import/preview` → показать `rows_total`, `rows_valid`, `rows_invalid` + список `unmapped_regions` (raw_text + occurrences) + первые 10 строк preview
   - Step 3: **Region → org mapping table:** для каждого unmapped_region — `v-autocomplete` с организациями + опция «Оставить как текст». Кнопка «Применить ко всем регионам» (используя текущий mapping).
   - Step 4: «Подтвердить импорт» → POST `/api/vehicles-import/commit` с `{session_id, region_mapping, default_owner_org_id, conflict_strategy: 'skip'}` → показать результат `{inserted, updated, skipped, errors[]}` → закрыть диалог + reload list.
5. **localStorage layout** для пресетов фильтров и порядка колонок: `vehicles_list_layout_u${userId}`.
6. **Error UI:** все ошибки через `err.code/err.message` + диалог с кнопкой «Скопировать» (Lesson 2026-05-13).
7. **Pre-push:** grep duplicate let/const + проверить bundle hash после deploy.
8. Commit message: `feat(29-16): frontend VehicleListView + VehicleImportDialog — OrdersView pattern + Excel import`
