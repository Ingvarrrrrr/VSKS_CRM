## Risks / Gotchas
- **`/property/vehicles/dashboard` vs `/property/vehicles/:id`** конфликт — решён через regex `:id(\\d+)`. **Без regex** Vue Router выбирает routes по порядку — `dashboard` должен идти ДО `:id`. С regex — порядок не важен.
- **`authStore.hasTab('vehicles')`** — проверить что метод существует. Если нет — добавить либо использовать `authStore.tabs.includes('vehicles')`.
- **Lesson 2026-05-05 OOM:** AppBar.vue — большой файл, добавление новой группы не должно сильно увеличить bundle. Multi-stage Dockerfile уже работает.
- **Lesson 2026-05-05 duplicate let/const:** OBLIGATORY pre-push grep.
- **Frontend стартует ДО backend полностью** — если router.beforeEach фильтрует по `hasTab('vehicles')` и backend ещё не отдал permissions, AppBar группа может не появиться. Должно работать через reactive watch.
