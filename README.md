# CRM система для управления договорами и подрядчиками

## Описание проекта

Система для управления данными подрядчиков, договоров, формирования служебных записок, договоров и технических заданий. Система предназначена для работы в разных городах с возможностью одновременного внесения данных несколькими пользователями.

## Основной функционал

### ✅ Управление контрагентами
- Внесение данных о контрагентах (вручную, из Word/PDF, из таблицы)
- Автозаполнение реквизитов при выборе контрагента
- Хранение полных реквизитов

### ✅ Управление договорами
- Создание договоров с составом (товары/услуги)
- Управление статусами (плановый, подтвержденный, ведутся работы)
- Отслеживание стадий исполнения
- Плановые даты поставки/исполнения

### ✅ Обработка платежей
- Загрузка данных о платежах из Excel
- Автоматическая сверка с договорами
- Отметка оплаченных договоров

### ✅ Формирование документов
- Лист согласования (автозаполнение)
- Договоры (на основе шаблонов)
- Служебные записки на закупку
- Служебные записки на оплату

### ✅ Категоризация по ФЭО
- Направление расходов по категориям ФЭО
- Тип расходов в соответствии с ФЭО
- Зависимости между категориями

### ✅ Дашборд и отчетность
- Интерактивный дашборд по субсидиям
- Метрики: Общий объём, Законтрактовано, Поставлено, Оплачено
- Графики разбивки по товарам/услугам
- Реестр заключённых договоров

## Архитектура

### Основная платформа: Google Sheets + Google Apps Script

**Преимущества:**
- ✅ Бесплатная платформа
- ✅ Совместная работа из коробки
- ✅ Уже есть начальный код
- ✅ Простое развертывание

**Структура:**
```
Google Sheets:
├── GoodsService (основная таблица)
├── Контрагенты_список
├── Категории_из_ФЭО
├── Категории_из_приложения
├── Дашборд
└── Реестр_договоров

Google Apps Script:
├── Code.gs (основная логика)
├── ContractDialog.html (форма договора)
└── ContractorDialog.html (форма контрагента)
```

### Дополнительно: n8n для автоматизации

**Применение:**
- Автоматизация загрузки платежей
- Синхронизация данных
- Генерация отчетов
- Уведомления
