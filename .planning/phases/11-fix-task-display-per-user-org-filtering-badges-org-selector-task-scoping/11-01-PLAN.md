```python
new_tasks_q = select(func.count(Task.id)).where(

if org_id is not None:
```

**Change A — filteredGeneralTasks computed (fixes Bug 2)**

```typescript
  if (selectedOrgId.value === null) return generalTasks.value
```

Check if the project uses mitt or a similar event bus: `grep -rn "mitt\|eventBus\|emitter" frontend/src/ | head -10`.

If an event bus exists, emit `org-selected` from `selectOrg()` in MyTasksView and listen in AppBar.

If no event bus: use a simpler approach — store `selectedOrgId` in localStorage when org is selected, and have AppBar pass it when calling `/tasks/badges`.

Simplest correct approach (no architecture change):

In MyTasksView.vue, update `selectOrg()`:
```typescript
function selectOrg(orgId: number | null) {
  selectedOrgId.value = orgId
  // Persist for AppBar badge filtering
  if (orgId !== null) {
    localStorage.setItem('active_org_id', String(orgId))
  } else {
    localStorage.removeItem('active_org_id')
  }
}
```

In AppBar.vue (`frontend/src/components/AppBar.vue`), update `loadBadges()`:
```typescript
async function loadBadges() {
  try {
    const activeOrgId = localStorage.getItem('active_org_id')
    const url = activeOrgId ? `/tasks/badges?org_id=${activeOrgId}` : '/tasks/badges'
    const data = await apiFetch<any>(url)
    badgeNewTasks.value = data.new_tasks || 0
    badgeTaskChanges.value = data.task_changes || 0
    badgeNewPurchases.value = data.new_purchases || 0
    badgePurchaseChanges.value = data.purchase_changes || 0
    badgeChatUnread.value = data.chat_unread || 0

}
```
