   - `Патриотика 2025 (5).xlsx` - основной файл с данными (лист GoodsService)
   - `Закупки ВСКС и новые территории.xlsx` - дополнительные данные

2. **Шаблоны договоров:**
   - Договоры поставки (Минпрос, Минтруд, ФАДМ, Регионы)

   - Договоры ГПХ (с самозанятыми и физ. лицами)

3. **Другие документы:**
   - Лист согласования
   - Служебные записки на закупку
   - Служебные записки на оплату

## Ключевые выводы

### 1. Множественность типов договоров

Система должна поддерживать:
- **Договоры поставки** (товары)
- **Договоры на оказание услуг** (с разными типами отчетности)
- **Договоры ГПХ** (с самозанятыми и физ. лицами, с РИД и без)
- **Договоры на ремонт ТС**

Каждый тип имеет свои специфические поля.

### 2. Разные ведомства = разные шаблоны

- **Минпрос** - свои шаблоны договоров
- **Минтруд** - свои шаблоны договоров
- **ФАДМ** - свои шаблоны договоров
- **Регионы** - свои шаблоны договоров

При формировании договора нужно выбирать правильный шаблон.

### 3. Состав договора - ключевой элемент

**Важно:** Договор может содержать множество позиций (товаров/услуг). Например:
- Договор: "Поставка оргтехники"
- Состав: "Монитор 5 шт.", "Планшет 3 шт.", "Принтер 2 шт."

Каждая позиция должна иметь:
- Наименование
- Количество
- Единицу измерения
- Цену за единицу
- Итоговую стоимость
- Категоризацию ФЭО

### 4. Категоризация ФЭО - сложная система зависимостей

Система категорий имеет 4 уровня с зависимостями:
1. Направление расходов по категориям ФЭО
2. Тип расходов в соответствии с ФЭО (зависит от 1)
3. Направление расходов из приложений к ФЭО (зависит от 2)
4. Тип расходов конкретизированный (зависит от 3)

### 5. Множество статусов и стадий

Договор проходит через множество стадий:
- Планирование
- Подтверждение
- Исполнение
- Приемка
- Оплата
- Завершение

Каждая стадия должна отслеживаться.

## Рекомендуемая структура формы

### Архитектура: Многостраничная форма с вкладками

**Преимущества:**
- Удобная навигация
- Логическая группировка полей
- Не перегружает интерфейс
- Позволяет сохранять прогресс по вкладкам

### Структура вкладок:

#### Вкладка 1: "Основная информация" (обязательная)

**Блок: Тип договора**
- Тип договора (выбор: поставка / услуги / ГПХ / ремонт ТС)
- Вид договора (разовый / рамочный)
- Субсидия (выбор из списка)
- Номер закупки
- Номер заказа внутри закупки / Период оказания услуг

**Блок: Предмет договора**
- Предмет договора (краткое описание)
- Детальное описание (расширенное поле)
- Основание для закупки

**Блок: Контрагент**
- Контрагент (выбор из списка с поиском)
- Кнопка "Добавить контрагента" (открывает форму)
- Кнопка "Загрузить из файла" (Word/PDF/Excel)

**Блок: Сроки**
- Дата заключения договора
- Плановая дата начала исполнения
- Плановая дата окончания исполнения
- Срок исполнения (в днях)

**Блок: Статусы**
- Статус договора (выпадающий список)
- Статус закупки (выпадающий список)
- Стадия исполнения (настраиваемое поле)

---

#### Вкладка 2: "Состав договора" (обязательная)

**Таблица позиций:**

| № | Наименование | Количество | Ед. изм. | Цена за ед. | НДС | Стоимость | Действия |
|---|--------------|------------|----------|-------------|-----|-----------|----------|
| 1 | [ввод]      | [ввод]     | [список]  | [ввод]      | [%] | [авто]    | [удалить] |

**Кнопки:**
- "Добавить позицию" (добавляет новую строку)
- "Импорт из Excel" (массовый импорт позиций)
- "Копировать позицию" (дублирование строки)

**Итоги (автоматический расчет):**
- Количество позиций
- Общая стоимость без НДС
- Сумма НДС
- Общая стоимость с НДС

**Для каждой позиции дополнительно:**
- Технические характеристики (для товаров)
- Описание услуги (для услуг)
- Гарантийный срок (для товаров)
- Страна происхождения (для товаров)

---

#### Вкладка 3: "Финансы" (обязательная)

**Блок: Стоимость**
- Начальная (максимальная) цена контракта (НМЦК)
- Цена договора без НДС (автоматически из состава)
- Сумма НДС (автоматически)
- Цена договора с НДС (автоматически)
- Экономия (автоматически: НМЦК - Цена договора)
- Процент экономии (автоматически)

**Блок: Условия оплаты**
- Способ оплаты (безналичный / наличный)
- Форма оплаты (предоплата / постоплата / поэтапная)
- Размер аванса (% или сумма)
- Срок оплаты аванса (дней)
- Срок оплаты после приемки (дней)
- График платежей (если поэтапная) - таблица с датами и суммами

**Блок: Налогообложение**
- Применение НДС (да / нет)
- Ставка НДС (%)
- Основание освобождения от НДС (если не применяется)

**Блок: Исполнение (заполняется по мере исполнения)**
- Законтрактовано (фактически)
- Поставлено / Оказано услуг (фактически)
- Оплачено (фактически)
- Остаток к оплате (автоматически)
- Остаток к поставке (автоматически)

---

#### Вкладка 4: "Категоризация ФЭО" (обязательная)

**Система зависимых списков:**

1. **Направление расходов по категориям ФЭО**
   - Выпадающий список из листа "Категории_из_ФЭО"
   - При выборе → заполняется следующий список

2. **Тип расходов в соответствии с ФЭО**
   - Выпадающий список (зависит от выбора в п.1)
   - При выборе → заполняется следующий список

3. **Направление расходов из приложений к ФЭО**
   - Выпадающий список (зависит от выбора в п.2)
   - При выборе → заполняется следующий список

4. **Тип расходов конкретизированный**
   - Выпадающий список (зависит от выбора в п.3)
   - Или свободный ввод (если пользовательский тип)

**Примечание:** Категоризация применяется к каждой позиции состава договора отдельно, если позиции имеют разные категории.

## Специфические поля для разных типов договоров

### Для договоров поставки:
- Страна происхождения товара
- Производитель
- Технические характеристики
- Требования к упаковке
- Требования к маркировке
- Условия доставки
- Место доставки

### Для договоров на оказание услуг:
- Вид услуги
- Объем услуг (часы / занятия / выезды)
- Место оказания услуг
- Период оказания услуг
- График оказания услуг
- Форма отчетности (большая / малая)
- Периодичность отчетности
- Требования к исполнителю

### Для договоров ГПХ:
- ФИО исполнителя
- Паспортные данные
- Адрес регистрации
- ИНН (для самозанятых)
- СНИЛС
- Наличие РИД (да / нет)
- Описание РИД (если есть)

### Для договоров на ремонт ТС:
- Марка и модель ТС
- Гос. номер
- VIN номер
- Год выпуска
- Пробег
- Вид работ (ремонт / ТО / диагностика)
- Описание работ
- Запчасти (список с ценами)

## Рекомендации по реализации

### 1. Приоритет полей

**Обязательные поля (для сохранения договора):**
- Тип договора
- Субсидия
- Контрагент
- Предмет договора
- Хотя бы одна позиция в составе
- Статус договора

**Рекомендуемые поля:**
- Все финансовые показатели
- Сроки
- Категоризация ФЭО

**Опциональные поля:**
- Дополнительные условия
- Документы
- Комментарии

### 2. Валидация данных

- **ИНН:** проверка формата (10 или 12 цифр)
- **КПП:** проверка формата (9 цифр)
- **Суммы:** проверка на положительные числа
- **Даты:** проверка логики (дата начала < дата окончания)
- **Количество:** проверка на положительные числа
- **Проценты:** проверка диапазона (0-100%)

### 3. Автоматические расчеты

- Итоговая стоимость позиции = Количество × Цена за единицу × (1 + НДС%)
- Общая стоимость договора = Сумма всех позиций
- Экономия = НМЦК - Цена договора
- Процент экономии = (Экономия / НМЦК) × 100%
- Остаток к оплате = Цена договора - Оплачено
- Остаток к поставке = Плановое количество - Поставлено

### 4. Удобство использования

- **Автосохранение:** сохранение черновика каждые 30 секунд
- **История изменений:** отслеживание всех модификаций
- **Отмена изменений:** возможность откатить изменения
- **Копирование договора:** создание нового договора на основе существующего
- **Шаблоны:** сохранение часто используемых значений как шаблонов

### 5. Производительность

- **Ленивая загрузка:** загрузка данных вкладок только при открытии
- **Кэширование:** кэширование списков контрагентов, категорий и т.д.
- **Пакетная обработка:** обработка множественных операций пакетами
