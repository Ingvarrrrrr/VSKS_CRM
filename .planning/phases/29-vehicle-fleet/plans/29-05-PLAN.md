## Tasks
1. Создать `vehicle_attachments.py` с `router = APIRouter(prefix="/api/vehicle-attachments", tags=["vehicles"])` (отдельный префикс, чтобы не пересекаться с `/api/vehicles/{id:int}` catch-all). Импорт `Vehicle`, `VehicleAttachment` из models.
2. ALLOWED_MIME для vehicle_attachments — расширенный набор: `image/jpeg`, `image/png`, `image/webp`, `image/heic`, `application/pdf`, `application/msword`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`. MAX_SIZE = 25 * 1024 * 1024 (25MB).
3. `POST /api/vehicle-attachments/upload` — multipart upload. Form fields: `vehicle_id: int`, `kind: str` (одно из sts/pts/osago/kasko/dk/permit_to/photo/other), `name: str` (default = filename), `policy_number: str | None`, `issued_at: str | None`, `expires_at: str | None`. `require_action('vehicle.edit')` для vehicle_id. Visibility: vehicle.owner_org_id или assigned_org_id ∈ user.org_ids. Чтение `await file.read()` → bytes; вычислить `sha256 = hashlib.sha256(file_bytes).hexdigest()`. Dedup: `select(VehicleAttachment).where(vehicle_id=..., sha256=...)`. Если найден → 409 `{code: 'DUPLICATE_ATTACHMENT', message: 'Файл уже загружен', id: existing.id}`. Coerce issued_at/expires_at из ISO-строки в date если переданы. Создать VehicleAttachment. Возвращает `{id, name, kind, size, mime, sha256, uploaded_at}`.
4. `GET /api/vehicle-attachments?vehicle_id={id}` — список attachments для vehicle. Возвращает `List[VehicleAttachmentOut]` (без file_data) сортировка `kind ASC, uploaded_at DESC`.
5. `GET /api/vehicle-attachments/{att_id}/download` — отдача файла как StreamingResponse. Visibility check. Content-Disposition `attachment; filename="{att.name}"`. `media_type=att.mime`.
6. `GET /api/vehicle-attachments/{att_id}` — metadata одного файла (без file_data — для preview-логики).
7. `DELETE /api/vehicle-attachments/{att_id}` — удаление. `require_action('vehicle.edit')` + visibility.
8. `PATCH /api/vehicle-attachments/{att_id}` — обновить metadata (name, policy_number, issued_at, expires_at, kind). `_coerce_patch_value` с _DATE_FIELDS = {'issued_at','expires_at'}.
9. Создать `repair_attachments.py` — копия `vehicle_attachments.py` со следующими отличиями: prefix `/api/repair-attachments`, парент `VehicleRepair`, FK поле `repair_id`, kind ENUM-значения `'order_form'/'act'/'invoice'/'photo'/'other'`, БЕЗ полей policy_number/issued_at/expires_at. Visibility — через `repair.vehicle` JOIN (vehicle.owner_org_id или assigned_org_id ∈ user.org_ids).
10. В `__init__.py` зарегистрировать оба router ПОСЛЕ `vehicles.router`:
    ```python
    from app.routers import vehicle_attachments, repair_attachments
    app.include_router(vehicle_attachments.router)
    app.include_router(repair_attachments.router)
    ```
11. Commit message: `feat(29-05): vehicle_attachments + repair_attachments routers — bytea + SHA-256 dedup`

## Risks / Gotchas
- **localStorage расхождение `access_token` vs `auth_token`:** frontend должен использовать `apiFetch` из `api.ts`, НЕ raw fetch (Lesson 2026-05-13 + Gotcha file).
- **Lesson 2026-05-04 dict-detail:** все ошибки через `HTTPException(detail={code, message, ...})`.
- **bytea volume:** на проде НЕТ volume mount для bytea — данные лежат в БД, бэкап через pg_dump (Gotcha file). Ничего не делаем особенного — paттерн уже работает в purchase_files.
- **SHA-256 dedup scope** — только в рамках одного vehicle/repair (не глобальный). Одинаковый файл на двух разных vehicles — OK, две записи в БД.
- **kind validation:** в Pydantic схеме / валидации проверять что kind ∈ ENUM-значениях. Если пришёл unknown — 422.
- **expires_at для osago/kasko/dk обязателен?** Из D-11: «доп. поля для osago/kasko/dk» — не обязательны, но обычно заполняются. Не делать NOT NULL.
