## Risks / Gotchas
- **ENUM vs VARCHAR:** не использовать PG ENUM types (нельзя `CREATE TYPE IF NOT EXISTS`, придётся писать DO block). Хранить как VARCHAR(20) — проще миграция, валидация в Pydantic layer.
- **CHECK constraint в trip.py:** SQLAlchemy `CheckConstraint('driver_user_id IS NOT NULL OR driver_external_id IS NOT NULL', name='ck_trip_driver_xor')`.
- **JSONB props default:** `Column(JSONB, nullable=False, server_default='{}')` — НЕ `default={}` (mutable default trap).
- **registered_at, insurance_until, license_issued_at, license_expires_at, medical_cert_expires_at — Column(Date)** — придётся добавить в `_DATE_FIELDS` в PATCH endpoint (планы 29-04, 29-09). Записано в Definition of Done.
