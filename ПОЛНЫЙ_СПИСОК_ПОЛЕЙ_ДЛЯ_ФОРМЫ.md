# Полный список полей для формы договора/поставки

## Анализ на основе документов и требований

### Основная информация о договоре/поставке

#### Идентификация
- **Номер договора** (автогенерация или ручной ввод)
- **Дата заключения договора**
- **Номер закупки** (связь с закупкой)
- **Номер заказа внутри закупки** или **Период оказания услуг**
- **Тип договора** (поставка / оказание услуг / ГПХ / ремонт ТС)
- **Вид договора** (разовый / рамочный / долгосрочный)
- **Субсидия** (выбор из списка: Минпрос / Минтруд / ФАДМ / Регионы)
- **Наименование субсидии** (полное название)

#### Предмет договора
- **Предмет договора** (краткое описание)
- **Детальное описание предмета** (расширенное поле)
- **Основание для закупки** (обоснование необходимости)
- **Способ определения поставщика** (конкурс / аукцион / запрос котировок / единственный поставщик)

### Контрагент (Исполнитель/Поставщик)

#### Основные данные
- **Контрагент** (выбор из списка или добавление нового)
- **Полное наименование организации**
- **Краткое наименование**
- **ИНН**
- **КПП**
- **ОГРН** / **ОГРНИП**
- **ОКПО**
- **ОКТМО**

#### Руководство
- **ФИО руководителя**
- **Должность руководителя**
- **Основание, на котором действует** (Устав / Доверенность №___ от ___)
- **Доверенность** (номер, дата, кем выдана - если применимо)

#### Банковские реквизиты
- **Расчётный счёт**
- **Кореспондентский счёт**
- **БИК банка**
- **Наименование банка**
- **Адрес банка**

#### Адреса и контакты
- **Юридический адрес** (полный)
- **Почтовый адрес**
- **Фактический адрес**
- **Телефон организации** (основной)
- **Факс** (если есть)
- **E-mail организации**
- **Веб-сайт** (если есть)

#### Контактные лица
- **Контактное лицо** (ФИО)
- **Должность контактного лица**
- **Телефон контактного лица**
- **E-mail контактного лица**
- **Дополнительные контакты**

### Заказчик

#### Основные данные
- **Наименование заказчика** (обычно фиксированное)
- **ИНН заказчика**
- **КПП заказчика**
- **ОГРН заказчика**

#### Банковские реквизиты заказчика
- **Расчётный счёт заказчика**
- **Кореспондентский счёт заказчика**
- **БИК банка заказчика**
- **Наименование банка заказчика**

#### Адреса и контакты заказчика
- **Адрес заказчика**
- **Телефон заказчика**
- **E-mail заказчика**

### Состав договора (Товары/Услуги) - Множественный ввод

Для каждой позиции:
- **Наименование товара/услуги** (детальное описание)
- **Артикул** / **Код товара** (если применимо)
- **Плановое количество**
- **Единица измерения (ОКЕИ)** (шт. / кг / м² / м³ / комплект / услуга и т.д.)
- **Код ОКЕИ** (числовой код)
- **Плановая стоимость за единицу** (без НДС)
- **Итоговая цена за единицу товара** (с учетом всех условий)
- **НДС** (% или сумма)
- **Стоимость позиции** (итоговая, с НДС)
- **Страна происхождения товара** (для поставок)
- **Производитель** (для поставок)
- **Технические характеристики** (для товаров)
- **Требования к качеству** (ГОСТ, ТУ и т.д.)
- **Гарантийный срок** (для товаров)
- **Срок гарантийного обслуживания** (для услуг)

### Финансовые условия

#### Стоимость договора
- **Начальная (максимальная) цена контракта (НМЦК)**
- **Цена договора** (итоговая согласованная)
- **Цена договора без НДС**
- **Сумма НДС**
- **Цена договора с НДС**
- **Экономия** (разница между НМЦК и ценой договора)
- **Процент экономии**

#### Условия оплаты
- **Способ оплаты** (безналичный расчет / наличными)
- **Форма оплаты** (предоплата / постоплата / поэтапная)
- **Размер аванса** (% или сумма)
- **Срок оплаты аванса** (дней после подписания)
- **Срок оплаты** (дней после приемки / оказания услуг)
- **График платежей** (если поэтапная оплата)
- **Условия оплаты** (детальное описание)

#### Налогообложение
- **Применение НДС** (да / нет)
- **Ставка НДС** (%)
- **Основание освобождения от НДС** (если не применяется)

### Сроки и графики

#### Сроки исполнения
- **Дата начала исполнения** (для услуг)
- **Срок исполнения договора** (количество дней / календарных дней / рабочих дней)
- **Дата окончания исполнения** (расчетная)
- **Плановая дата поставки/исполнения** (конкретная дата)
- **Фактическая дата поставки/исполнения** (заполняется после исполнения)
- **Срок действия договора** (с ___ по ___)

#### Графики
- **График поставки** (для поставок с несколькими этапами)
- **График выполнения работ** (для услуг)
- **График платежей** (если поэтапная оплата)
- **Календарный план** (детальный план по датам)

### Статусы и стадии

#### Статус договора
- **Статус договора** (выбор из списка):
  - Плановый
  - Подтвержденный
  - Ведутся работы
  - Исполнен
  - Расторгнут
  - Просрочен

#### Стадия исполнения
- **Стадия исполнения** (настраиваемое поле):
  - Подготовка документов
  - Согласование
  - Подписание
  - Исполнение
  - Приемка
  - Оплата
  - Завершен

#### Дополнительные статусы
- **Статус закупки** (плановый / подтвержденный / ведутся работы)
- **Статус оплаты** (не оплачен / частично оплачен / оплачен)
- **Статус поставки** (не поставлено / частично поставлено / поставлено)
- **Статус приемки** (не принято / частично принято / принято)

### Категоризация по ФЭО

#### Категории расходов
- **Направление расходов по категориям в соответствии с ФЭО** (выбор из списка)
- **Тип расходов в соответствии с ФЭО** (зависит от направления)
- **Направление расходов из приложений к ФЭО** (выбор из списка)
- **Тип расходов конкретизированный** (пользовательский тип для удобства)

### Исполнение договора

#### Финансовые показатели исполнения
- **Общая сумма договора** (плановая)
- **Законтрактовано** (фактически заключено)
- **Поставлено** (фактически поставлено / оказано услуг)
- **Оплачено** (фактически оплачено)
- **Остаток к оплате**
- **Остаток к поставке**

#### Количественные показатели
- **Плановое количество** (общее по договору)
- **Поставленное количество** (фактическое)
- **Остаток к поставке** (по количеству)

### Документооборот

#### Документы договора
- **Номер протокола** (если был конкурс/аукцион)
- **Дата протокола**
- **Протокол рассмотрения заявок** (ссылка/файл)
- **Протокол вскрытия конвертов** (ссылка/файл)
- **Извещение о закупке** (ссылка/файл)
- **Техническое задание** (ссылка/файл)
- **Спецификация** (ссылка/файл)
- **Приложения к договору** (список файлов)

#### Документы исполнения
- **Акт выполненных работ** (дата, номер, ссылка)
- **Акт приемки-передачи** (дата, номер, ссылка)
- **Счет** (дата, номер, ссылка)
- **Счет-фактура** (дата, номер, ссылка)
- **УПД** (универсальный передаточный документ) (дата, номер, ссылка)
- **Накладная** (для поставок) (дата, номер, ссылка)

#### Документы оплаты
- **Платежное поручение** (дата, номер, сумма, ссылка)
- **Выписка банка** (дата, ссылка)
- **Дата оплаты** (фактическая)

### Дополнительные условия

#### Ответственность сторон
- **Размер неустойки** (% или фиксированная сумма)
- **Условия применения неустойки**
- **Штрафные санкции**

#### Особые условия
- **Особые условия договора** (текстовое поле)
- **Дополнительные условия** (текстовое поле)
- **Условия доставки** (для поставок)
- **Место доставки** (адрес)
- **Условия приемки** (описание процедуры)
- **Условия хранения** (если применимо)
- **Требования к упаковке** (для поставок)
- **Требования к маркировке** (для поставок)

#### Гарантии и качество
- **Гарантийный срок** (для товаров)
- **Срок гарантийного обслуживания** (для услуг)
- **Требования к качеству** (ГОСТ, ТУ, технические условия)
- **Порядок предъявления претензий**

#### Прочее
- **Форс-мажорные обстоятельства** (описание)
- **Порядок разрешения споров**
- **Условия расторжения договора**
- **Прочие условия**

### Согласование и утверждение

#### Лист согласования
- **Дата формирования листа согласования**
- **Согласующие лица** (список с подписями)
- **Дата согласования** (для каждого согласующего)
- **Статус согласования** (в процессе / согласовано / отклонено)

#### Подписание
- **Дата подписания договора заказчиком**
- **Дата подписания договора исполнителем**
- **Подписант от заказчика** (ФИО, должность)
- **Подписант от исполнителя** (ФИО, должность)
- **Основание полномочий подписанта** (для исполнителя)

### Служебные записки

#### Служебная записка на закупку
- **Дата формирования служебной записки**
- **Обоснование закупки** (детальное описание необходимости)
- **Обоснование НМЦК** (как рассчитана цена)
- **Обоснование способа определения поставщика**
- **Предлагаемый поставщик** (если единственный)
- **Обоснование выбора поставщика**

#### Служебная записка на оплату
- **Дата формирования служебной записки**
- **Основание для оплаты** (ссылка на акт, накладную и т.д.)
- **Сумма к оплате**
- **Срок оплаты**
- **Обоснование срочности** (если досрочная оплата)

### Технические параметры (для поставок)

#### Характеристики товаров
- **Марка** / **Модель**
- **Производитель**
- **Страна происхождения**
- **Артикул**
- **Серийный номер** (если применимо)
- **Технические характеристики** (детальное описание)
- **Соответствие ГОСТ/ТУ**
- **Сертификаты соответствия** (номера, даты)

### Параметры для услуг

#### Характеристики услуг
- **Вид услуги** (консультационные / образовательные / ремонтные и т.д.)
- **Объем услуг** (количество часов / занятий / выездов и т.д.)
- **Место оказания услуг** (адрес)
- **Период оказания услуг** (с ___ по ___)
- **График оказания услуг** (расписание)
- **Требования к исполнителю** (квалификация, опыт)
- **Форма отчетности** (большая / малая отчетность)
- **Периодичность отчетности** (ежемесячно / ежеквартально и т.д.)

### Параметры для ГПХ договоров

#### Данные физического лица / самозанятого
- **ФИО исполнителя**
- **Паспортные данные** (серия, номер, кем выдан, дата выдачи)
- **Адрес регистрации**
- **Адрес фактического проживания**
- **ИНН** (для самозанятых)
- **СНИЛС**
- **Телефон**
- **E-mail**
- **Наличие РИД** (да / нет) - Результаты интеллектуальной деятельности
- **Описание РИД** (если есть)

### Параметры для ремонта ТС

#### Данные транспортного средства
- **Марка и модель ТС**
- **Гос. номер**
- **VIN номер**
- **Год выпуска**
- **Пробег**
- **Вид работ** (ремонт / ТО / диагностика)
- **Описание работ** (детальное)
- **Запчасти** (список с ценами)
- **Стоимость работ**
- **Стоимость запчастей**
- **Общая стоимость**

### Системные поля

#### Метаданные
- **Дата создания записи**
- **Дата последнего изменения**
- **Автор записи** (кто создал)
- **Последний редактор** (кто последний раз изменял)
- **Город** / **Регион** (где ведется работа)
- **Ответственный сотрудник** (ФИО)
- **Комментарии** (общее текстовое поле для заметок)

#### Связи
- **Связанные договора** (если есть доп. соглашения)
- **Дополнительные соглашения** (номера и даты)
- **Родительский договор** (если это доп. соглашение)
- **Связанные закупки** (если несколько закупок по одному договору)

## Группировка полей для формы

### Вкладка 1: Основная информация
- Все поля из раздела "Основная информация о договоре/поставке"
- Контрагент (выбор)
- Заказчик (обычно фиксированные данные)

### Вкладка 2: Состав договора
- Таблица с множественным вводом товаров/услуг
- Кнопка "Добавить позицию"
- Кнопка "Удалить позицию"
- Автоматический расчет итоговой суммы

### Вкладка 3: Финансы и сроки
- Все финансовые условия
- Сроки исполнения
- Графики (если применимо)

### Вкладка 4: Категоризация ФЭО
- Все поля категоризации
- Зависимые списки

### Вкладка 5: Статусы и исполнение
- Статусы договора
- Стадии исполнения
- Финансовые показатели исполнения
- Количественные показатели

### Вкладка 6: Документы
- Список всех документов
- Возможность загрузки файлов
- Ссылки на документы

### Вкладка 7: Дополнительно
- Особые условия
- Дополнительные параметры
- Комментарии

## Рекомендации по реализации

1. **Многостраничная форма** с вкладками для удобства навигации
2. **Автозаполнение** реквизитов контрагента при выборе
3. **Валидация данных** (ИНН, КПП, суммы, даты)
4. **Автоматические расчеты** (суммы, остатки, проценты)
5. **Зависимые списки** для категорий ФЭО
6. **Сохранение черновиков** для незавершенных форм
7. **История изменений** для отслеживания модификаций
8. **Печать/экспорт** формы в PDF
