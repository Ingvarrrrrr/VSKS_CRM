<interfaces>
Существующий `n8n_workflows/fabrikant_publish.json` содержит следующие nodes (в порядке выполнения):
1. Webhook (POST, path: "fabrikant-publish") — принимает payload от CRM
2. Code node — разбирает body, формирует fabrikantPayload, extracts publicationId
3. HTTP Request — вызов SOAP API Фабрикант (заглушка)
4. IF node — проверяет success из ответа
5. Code node (success) — формирует callback payload с externalId
6. HTTP Request — PATCH /api/publications/{publicationId}/status со status="published"
7. Code node (error) — формирует callback payload с error
8. HTTP Request — PATCH /api/publications/{publicationId}/status со status="error"
9. respondToWebhook — возвращает 200 в CRM

Callback URL pattern: http://backend:8000/api/publications/{{ $json.publicationId }}/status
Body для success callback: { status: "published", external_id: "...", external_url: "..." }
Body для error callback: { status: "error", error_text: "..." }
</interfaces>
</context>

Создать файл `n8n_workflows/roseltorg_publish.json` — n8n workflow для публикации на Росэлторг.Бизнес.

Структура workflow (9 nodes, копия Фабрикант с изменениями):

**Node 1 — Webhook:**
- type: "n8n-nodes-base.webhook"
- name: "Webhook Росэлторг"
- parameters: path = "roseltorg-publish", method = "POST", responseMode = "responseNode"

**Node 2 — Code (Подготовка + проверка токена):**
- type: "n8n-nodes-base.code"
- name: "Подготовка данных"
- JavaScript:
```javascript
const data = $input.first().json.body || $input.first().json;
const token = $env.ROSELTORG_TOKEN || '';
const procedureType = data.procedure_type || 'request_quotations';

const TEMPLATE_IDS = {
  'request_quotations': 'QUOTATION_REQUEST',
  'request_proposals':  'PROPOSAL_REQUEST',
  'competition':        'OPEN_COMPETITION',
  'auction':            'OPEN_AUCTION',
};
const templateId = TEMPLATE_IDS[procedureType] || 'QUOTATION_REQUEST';

return [{
  json: {
    publicationId: data.publication_id,
    hasToken: token !== '',
    token,
    templateId,
    procedureType,
    roseltorgPayload: {
      templateId,
      lotName: data.subject || ('Закупка #' + data.purchase_id),
      startPrice: data.nmck || 0,
      currency: 'RUB',
      items: (data.items || []).map(function(i) {
        return { name: i.item_name, quantity: i.quantity, unit: i.unit, unitPrice: i.unit_price };
      }),
    },
  }
}];
```

**Node 3 — IF (проверка токена):**
- type: "n8n-nodes-base.if"
- name: "Есть токен?"
- condition: `$json.hasToken` === true (boolean)
- TRUE branch → Node 4 (HTTP Request Росэлторг)
- FALSE branch → Node 6 (Error callback)

**Node 4 — HTTP Request (Росэлторг API — заглушка):**
- type: "n8n-nodes-base.httpRequest"
- name: "Вызов Росэлторг API"
- method: POST
- url: "https://rb.roseltorg.ru/api/v1/lots"
- headers: `Authorization: Bearer {{ $json.token }}`
- body (JSON): `{{ $json.roseltorgPayload }}`
- continueOnFail: true (чтобы не ронять workflow при недоступности API)

**Node 5 — IF (проверка успеха от Росэлторг):**
- type: "n8n-nodes-base.if"
- name: "Успешно?"
- condition: проверить `$json.id` существует (реальный Росэлторг возвращает id в ответе) или `$json.success === true`
- TRUE branch → Node 7 (success callback)
- FALSE branch → Node 8 (error callback с ответом API)

**Node 6 — Code (Error — нет токена):**
- type: "n8n-nodes-base.code"
- name: "Ошибка: нет токена"
- JavaScript:
```javascript
const { publicationId } = $input.first().json;
return [{ json: {
  publicationId,
  callbackBody: {
    status: 'error',
    error_text: 'Требуется Bearer Token Росэлторг — настройте в параметрах n8n (переменная ROSELTORG_TOKEN)',
  }
}}];
```
Этот node соединён с Node 9 (PATCH error callback).

**Node 7 — Code (Success callback data):**
- type: "n8n-nodes-base.code"
- name: "Данные успеха"
- JavaScript:
```javascript
const prev = $input.first().json;
return [{ json: {
  publicationId: prev.publicationId,
  callbackBody: {
    status: 'published',
    external_id: String(prev.id || prev.lotId || 'ROSELTORG-' + Date.now()),
    external_url: 'https://rb.roseltorg.ru/lot/' + (prev.id || ''),
  }
}}];
```

**Node 8 — Code (Error callback data — API вернул ошибку):**
- type: "n8n-nodes-base.code"
- name: "Ошибка API Росэлторг"
- JavaScript:
```javascript
const prev = $input.first().json;
return [{ json: {
  publicationId: prev.publicationId,
  callbackBody: {
    status: 'error',
    error_text: 'Ошибка API Росэлторг: ' + JSON.stringify(prev.message || prev.error || prev),
  }
}}];
```

**Node 9 — HTTP Request (PATCH success callback):**
- type: "n8n-nodes-base.httpRequest"
- name: "Callback успех в CRM"
- method: PATCH
- url: `http://backend:8000/api/publications/{{ $json.publicationId }}/status`
- body: `{{ $json.callbackBody }}`

**Node 10 — HTTP Request (PATCH error callback):**
- type: "n8n-nodes-base.httpRequest"
- name: "Callback ошибка в CRM"
- method: PATCH
- url: `http://backend:8000/api/publications/{{ $json.publicationId }}/status`
- body: `{{ $json.callbackBody }}`

**Node 11 — Respond to Webhook:**
- type: "n8n-nodes-base.respondToWebhook"
- name: "Ответ 200"
- responseBody: `{"ok": true}`
