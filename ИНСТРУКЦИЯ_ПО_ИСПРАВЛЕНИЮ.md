# Инструкция по исправлению проблем

## Проблемы, которые нужно исправить:

1. ❌ Нет зависимостей между направлениями ФЭО
2. ❌ Нет данных для выпадающих списков
3. ❌ Не появляется интерфейс (меню)
4. ❌ Скрипт только создает страницы, но не заполняет данными

## Решение: Пошаговые действия

### ШАГ 1: Обновите скрипт

1. Откройте файл `ПОЛНЫЙ_СКРИПТ_БАЗЫ_ДАННЫХ.gs`
2. Скопируйте ВЕСЬ код (Ctrl+A, Ctrl+C)
3. Откройте ваш файл Google Sheets
4. Откройте **Расширения → Apps Script**
5. Удалите весь старый код
6. Вставьте новый код
7. Сохраните (Ctrl+S)

### ШАГ 2: Создайте структуру (если еще не создана)

1. В Apps Script выберите функцию `createDatabaseStructure`
2. Нажмите **Выполнить** (▶)
3. Должны создаться 10 листов

### ШАГ 3: Импортируйте данные (ВАЖНО!)

**Это ключевой шаг!** Без данных в справочниках выпадающие списки не будут работать.

**Вариант А: Импорт из текущего файла (если данные в том же файле)**

1. В Apps Script выберите функцию `quickImportFromCurrentFile`
2. Нажмите **Выполнить** (▶)
3. Дождитесь завершения
4. Проверьте результаты в диалоговом окне

**Вариант Б: Через меню (если меню появилось)**

1. В Google Sheets нажмите **📥 Импорт данных → 📄 Импорт из текущего файла**
2. Дождитесь завершения

**Вариант В: Импорт из другого файла**

1. В Google Sheets нажмите **📥 Импорт данных → 📂 Импорт из Google Sheets файла**
2. Выберите файл "Патриотика"
3. Нажмите **Импортировать**

### ШАГ 4: Обновите выпадающие списки ФЭО

**После импорта данных ОБЯЗАТЕЛЬНО выполните:**

1. В Apps Script выберите функцию `updateFEODropdowns`
2. Нажмите **Выполнить** (▶)
3. Или через меню: **📥 Импорт данных → 🔄 Обновить выпадающие списки ФЭО**

**Это создаст выпадающие списки в столбце "Направление расходов ФЭО" (AI)**

### ШАГ 5: Создайте меню вручную

Если меню не появилось:

1. В Apps Script выберите функцию `createMenu`
2. Нажмите **Выполнить** (▶)
3. Вернитесь в Google Sheets
4. Обновите страницу (F5)
5. Меню должно появиться

### ШАГ 6: Проверьте работу зависимостей

1. Откройте лист **GoodsService**
2. В строке 2 выберите значение в столбце **AI** (Направление расходов ФЭО)
3. Проверьте, что в столбце **AJ** появился выпадающий список
4. Выберите значение в **AJ**
5. Проверьте, что в столбце **AK** появился список
6. И так далее

## Диагностика проблем

   - Сколько файлов найдено для импорта

## Если что-то не работает

### Проблема: Данные не импортируются

**Решение:**
1. Проверьте логи выполнения в Apps Script (Вид → Логи выполнения)
2. Убедитесь, что файл "Патриотика" содержит листы:
   - GoodsService
   - Категории_из_ФЭО
   - Категории_из_приложения
3. Проверьте названия листов - они должны совпадать точно

### Проблема: Выпадающие списки не появляются

**Решение:**
1. Убедитесь, что данные импортированы в листы "Категории_из_ФЭО" и "Категории_из_приложения"
2. Запустите функцию `updateFEODropdowns()` вручную
3. Проверьте, что в листах есть данные (не только заголовки)

### Проблема: Зависимости не работают

**Решение:**
1. Убедитесь, что данные в листах категорий заполнены правильно:
   - Первый столбец - название категории
   - Остальные столбцы - подкатегории
2. Проверьте, что функция `onEdit` работает (она должна быть в коде)
3. Попробуйте вручную выбрать категорию в столбце AI и посмотрите логи

### Проблема: Меню не появляется

**Решение:**
1. Запустите функцию `createMenu()` вручную в Apps Script
2. Обновите страницу Google Sheets (F5)
3. Проверьте логи выполнения на ошибки

## Важные моменты

1. **Импорт данных ОБЯЗАТЕЛЕН** - без данных в справочниках выпадающие списки не будут работать
2. **Обновление списков ОБЯЗАТЕЛЬНО** - после импорта нужно запустить `updateFEODropdowns()`
3. **Порядок действий важен:**
   - Сначала создайте структуру
   - Потом импортируйте данные
   - Потом обновите выпадающие списки
   - Потом создайте меню

## Быстрая проверка

Запустите функцию `testAndFix()` - она покажет все проблемы и даст рекомендации.
