## Risks / Gotchas
- **Lesson 2026-05-05:** дубли let/const в StaffView.vue (большой файл) — высокий риск. OBLIGATORY pre-push grep.
- **type="date" inputs возвращают строку YYYY-MM-DD.** Backend `_coerce_patch_value` приведёт к `date`. Пустая строка `''` → `null` логика на frontend.
- **Reactivity:** `editDialog` — `ref({ ... })`. Прямое мутирование `editDialog.value.can_drive = true` работает. Не пытаться `Vue.set` (Vue 3).
- **PATCH PUT mismatch:** проверить какой метод использует существующий save — PATCH или PUT. Если PUT — backend whitelist уже включает новые поля (план 29-09).
- **Lesson 2026-05-04 NameError-equivalent на frontend:** новые TS-имена должны быть в `editDialog` interface если он строго типизирован. Если `any` — OK.
- **Error UI:** при PATCH 422 / 409 — показать `err.detail.code` (Lesson 2026-05-04 — backend handler пакует dict-detail в верхний level `code/message/details`).
