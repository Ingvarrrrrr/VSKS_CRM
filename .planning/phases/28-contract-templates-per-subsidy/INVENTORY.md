### Условные блоки

1. **ИП vs Юр.лицо** — все договоры содержат ОБА варианта через `/` (например: `___ (ИП ___) ... / ___________________ (____________)`). В шаблоне нужен `{%- if contractor_org_type == 'ИП' %} ... {%- else %} ... {%- endif %}`.

2. **НДС vs Без НДС** — все договоры содержат 3 варианта через `/`: НДС 20%, НДС 5%, освобождение. Нужен вложенный `{% if vat_applicable %}{% if vat_rate == 20 %}...{% elif vat_rate == 5 %}...{% endif %}{% else %}...{% endif %}`.

3. **Срок исполнения** — все договоры услуг имеют 3 варианта через `/`: `с момента по дату`, `с даты по дату`, `с момента по дату (включительно)`. Режим `service_term_mode` (range/duration/deadline) уже есть в PLACEHOLDERS.md.

4. **Субсидийный блок** — только Минтруд содержит жёстко зашитый `№ 149-10-2025-043`. ФАДМ/Минпрос оставляют `___`. Нужно `{% if subsidy_agreement_text %}{{ subsidy_agreement_text }}{% else %}___{% endif %}` или просто подставлять переменную.

5. **ТЗ как Приложение 1** — все договоры услуг и поставки содержат ТЗ как встроенное Приложение. Договор ТЗ ШАБЛОН.docx — единственный самостоятельный файл с ТЗ. При генерации doc_type=`contract_tz` нужно генерировать отдельно.
