# Пошаговая инструкция создания базы данных

## Что такое база данных?

**База данных** - это файл Google Sheets, в котором будут храниться все данные. Вы создаете этот файл, запускаете скрипты, и они создают структуру (листы с таблицами).

## Шаг 1: Создание файла Google Sheets

1. Откройте https://sheets.google.com
2. Нажмите **"Пустой файл"** или **"Blank"**
3. Назовите файл, например: **"CRM_Договоры_База_Данных"**
4. Сохраните файл

**Это и есть ваша база данных!**

## Шаг 2: Открытие редактора скриптов

1. В созданном файле Google Sheets нажмите **Расширения → Apps Script**
   (или **Extensions → Apps Script**)
2. Откроется редактор кода

## Шаг 3: Добавление полного скрипта

1. В редакторе Apps Script удалите весь существующий код (если есть)
2. **Скопируйте весь код из файла `ПОЛНЫЙ_СКРИПТ_БАЗЫ_ДАННЫХ.gs`**
   - Этот файл содержит ВСЕ функции в одном месте:
     - Создание структуры БД
     - Зависимости категорий ФЭО
     - Импорт данных с GUI
3. Вставьте в редактор Apps Script
4. Нажмите **Сохранить** (Ctrl+S) или иконку дискеты 💾
5. Назовите проект: **"CRM Database"**

## Шаг 4: Запуск создания структуры

1. В редакторе Apps Script вверху выберите функцию `createDatabaseStructure`
2. Нажмите кнопку **Выполнить** (▶) или **Run**
3. При первом запуске появится окно авторизации:
   - Нажмите **"Проверить разрешения"** или **"Review permissions"**
   - Выберите свой аккаунт Google
   - Нажмите **"Разрешить"** или **"Allow"**
   - Может появиться предупреждение - нажмите **"Дополнительно"** → **"Перейти к..."**
4. Дождитесь завершения выполнения
5. Проверьте логи: **Вид → Логи выполнения** (View → Execution log)
6. Должно быть сообщение: **"Структура базы данных создана успешно!"**

## Шаг 5: Проверка созданных листов

Вернитесь в Google Sheets (закройте редактор скриптов или переключитесь на вкладку с таблицей).

**Проверьте, что созданы листы:**
- ✅ GoodsService
- ✅ Состав_договора
- ✅ Контрагенты
- ✅ Субсидии
- ✅ Категории_из_ФЭО
- ✅ Категории_из_приложения
- ✅ Платежи

**Если листы не созданы:**
- Проверьте логи выполнения в Apps Script
- Убедитесь, что скрипт выполнился без ошибок
- Попробуйте запустить функцию `createDatabaseStructure` еще раз

## Шаг 7: Обновление страницы и проверка меню

1. Вернитесь в Google Sheets
2. **Обновите страницу** (F5 или Ctrl+R)
3. **ВАЖНО:** После обновления должно появиться меню **"Импорт данных"** в верхней панели

**Если меню не появилось:**

### Вариант 1: Запуск функции onOpen вручную

1. Откройте **Расширения → Apps Script**
2. Выберите функцию `onOpen`
3. Нажмите **Выполнить** (▶)
4. Вернитесь в Google Sheets
5. Меню должно появиться

### Вариант 2: Проверка кода

Убедитесь, что в скрипте есть функция `onOpen()`:

```javascript
function onOpen() {
  var ui = SpreadsheetApp.getUi();
  ui.createMenu('Импорт данных')
    .addItem('Импорт из Google Sheets файла', 'showFileSelectionDialog')
    .addSeparator()
    .addItem('Импорт из текущего файла', 'importFromCurrentFile')
    .addToUi();
}
```

## Шаг 8: Импорт данных

1. В Google Sheets нажмите **Импорт данных → Импорт из Google Sheets файла**
2. Откроется диалоговое окно со списком файлов
3. Найдите файл "Патриотика" в списке
4. Кликните на него (он выделится)
5. Нажмите **"Импортировать"**
6. Дождитесь завершения импорта
7. Проверьте результаты

## Устранение проблем

### Проблема: Меню не появляется

**Решение:**
1. Убедитесь, что функция `onOpen()` есть в коде
2. Сохраните проект
3. Обновите страницу Google Sheets (F5)
4. Запустите функцию `onOpen()` вручную в Apps Script

### Проблема: Ошибка при выполнении скрипта

**Решение:**
1. Откройте **Вид → Логи выполнения** в Apps Script
2. Прочитайте сообщение об ошибке
3. Проверьте, что все скрипты скопированы полностью
4. Убедитесь, что нет синтаксических ошибок

### Проблема: Листы не создаются

**Решение:**
1. Проверьте логи выполнения
2. Убедитесь, что у вас есть права на создание листов
3. Попробуйте запустить функцию `createDatabaseStructure` еще раз

### Проблема: Файлы не находятся при импорте

**Решение:**
1. Убедитесь, что файл "Патриотика" существует в Google Sheets
2. Проверьте, что у вас есть доступ к файлу
3. Используйте поиск в диалоговом окне для поиска файла

## Структура файлов в проекте

В редакторе Apps Script у вас должно быть:

```
Code.gs (или несколько файлов .gs)
├── createDatabaseStructure() - создание структуры
├── onEdit() - обработка зависимостей ФЭО
├── onOpen() - создание меню
├── showFileSelectionDialog() - показ GUI для выбора файла
├── getAvailableFiles() - получение списка файлов
└── importDataFromFile() - импорт данных
```
