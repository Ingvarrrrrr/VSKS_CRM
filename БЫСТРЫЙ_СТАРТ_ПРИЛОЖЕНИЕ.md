# Быстрый старт - Локальное приложение CRM

## Шаг 1: Установка (один раз)

### Вариант А: Автоматическая установка (Windows)

1. Дважды кликните на файл **`install.bat`**
2. Дождитесь завершения установки
3. Готово!

### Вариант Б: Ручная установка

1. Установите Python 3.8+ с https://www.python.org/
2. Откройте командную строку в папке проекта
3. Выполните:
   ```bash
   pip install -r requirements.txt
   python create_excel_structure.py
   ```

## Шаг 2: Импорт данных (опционально)

Если у вас есть файл "Патриотика 2025 (5).xlsx":

1. Скопируйте файл в папку проекта
2. Выполните:
   ```bash
   python import_data.py "Патриотика 2025 (5).xlsx"
   ```

Или через GUI приложения (будет добавлено в следующей версии).

## Шаг 3: Запуск приложения

### Вариант А: Через bat-файл (Windows)

Дважды кликните на **`run.bat`**

### Вариант Б: Через командную строку

```bash
python main.py
```

## Использование

### Создание договора

1. Откройте вкладку **"📄 Договоры"**
2. Заполните форму:
   - Номер договора
   - Дата договора
   - Выберите субсидию
   - Выберите контрагента (или добавьте нового)
   - Добавьте позиции в состав договора
   - Заполните финансовые условия
   - **Выберите категории ФЭО через галочки** ✅
3. Нажмите **"💾 Сохранить договор"**

### Выбор категорий ФЭО

Категории выбираются через **чекбоксы (галочки)**:

- ✅ Отметьте нужные категории в разделе "Направление расходов по категориям ФЭО"
- ✅ Можно выбрать несколько категорий одновременно
- ✅ После выбора автоматически обновится список "Тип расходов ФЭО"
- ✅ Аналогично для категорий из приложения

### Добавление контрагента

1. Нажмите **"➕ Добавить контрагента"** в форме договора
2. Или перейдите на вкладку **"👥 Контрагенты"**
3. Заполните обязательные поля (Контрагент, ИНН)
4. Нажмите **"OK"**

## Устранение проблем

### Python не найден

Установите Python 3.8+ с https://www.python.org/  
При установке отметьте "Add Python to PATH"

### Ошибка при установке зависимостей

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Файл базы данных не создается

Запустите вручную:
```bash
python create_excel_structure.py
```

### Категории ФЭО не отображаются

Импортируйте данные:
```bash
python import_data.py "путь/к/файлу/Патриотика 2025 (5).xlsx"
```
