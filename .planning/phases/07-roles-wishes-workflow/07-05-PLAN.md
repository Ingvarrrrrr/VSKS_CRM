For each router file, add `require_role` to endpoints that currently only use `get_current_user` and should NOT be accessible by employees.

**Rules for which role to gate with:**
- Subsidies: `MANAGER_ROLES` — managers and above can view/manage subsidies
- Contracts: `MANAGER_ROLES` — managers and above for list/create/update (keep existing ADMIN_ROLES on delete/merge)
- Payments: `MANAGER_ROLES` — managers and above for list (keep existing require_role on create/delete)
- FEO Categories: `ADMIN_ROLES` — only admins manage FEO categories
- Users list: `ADMIN_ROLES` — only admins can list all users (keep existing roles on create/update/delete)

**For each file:**

1. **subsidies.py**: Add import `require_role, MANAGER_ROLES` (if not already imported). For EVERY endpoint that currently has only `current_user: User = Depends(get_current_user)`, change to `current_user: User = Depends(require_role(*MANAGER_ROLES))`. This includes:
   - list_subsidies
   - create_subsidy
   - update_subsidy
   - get_subsidy (if exists)
   - Any other endpoints without require_role
   Do NOT change any endpoint that already has require_role with a more restrictive set.

2. **contracts.py**: Already imports require_role. For `list_contracts` and `create_contract` and `update_contract` — change `current_user=Depends(get_current_user)` to `current_user=Depends(require_role(*MANAGER_ROLES))`. Keep existing `require_role(*ADMIN_ROLES)` on delete_contract and merge_contracts.

3. **payments.py**: For `list_payments` — change `_=Depends(get_current_user)` to `_=Depends(require_role(*MANAGER_ROLES))`. Add import for MANAGER_ROLES if not present. Keep existing require_role on create/delete.

4. **feo_categories.py**: Add import `require_role, ADMIN_ROLES` from `app.auth.jwt`. For all endpoints, change `current_user=Depends(get_current_user)` to `current_user=Depends(require_role(*ADMIN_ROLES))`.

5. **users.py**: For `list_users` — change `current_user: User = Depends(get_current_user)` to `current_user: User = Depends(require_role(*ADMIN_ROLES))`. Keep existing require_role on other endpoints. Keep `get_me` as `get_current_user` (every user can read their own profile).

**CRITICAL**: Do NOT change endpoints that need to remain accessible to all roles:
- users.py `get_me` — must stay `get_current_user`
- users.py `get_my_signature` / `upload_signature` — must stay `get_current_user`
- Any endpoint already gated with require_role — do NOT weaken it

**Pattern for the change:**
```python
# BEFORE:
async def list_subsidies(..., current_user: User = Depends(get_current_user)):

# AFTER:
async def list_subsidies(..., current_user: User = Depends(require_role(*MANAGER_ROLES))):
```

`require_role()` already returns the current_user object, so the variable name `current_user` stays the same and all downstream code works unchanged.
