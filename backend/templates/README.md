# Руководство по разметке шаблонов документов

Шаблоны — обычные `.docx` файлы (Microsoft Word), в которых переменные записываются в двойных фигурных скобках: `{{ переменная }}`. Движок — **docxtpl** (Jinja2).

> **Важно!** Переменные пишутся **строго на английском** и только внутри `{{ }}`. Русский текст вроде «г.» или «руб.» должен стоять **снаружи** скобок:
> `от {{ contract_date }} г.` — правильно
> `от {{ contract_date г. }}` — **ошибка**, документ не сформируется

---

## Доступные шаблоны

| Файл шаблона | Код (doc_type) | Документ |
|---|---|---|
| `service_note.docx` | `service_note` | Служебная записка на согласование закупки |
| `service_note_delivery.docx` | `service_note_delivery` | Служебная записка на выдачу товара |
| `service_note_payment.docx` | `service_note_payment` | Служебная записка на оплату |
| `contract.docx` | `contract` | Договор (стандартный) |
| `contract_tz.docx` | `contract_tz` | Договор + Техническое задание |
| `contract_fadm.docx` | `contract_fadm` | Договор ФАДМ (с проверкой обязательных полей) |
| `approval_sheet.docx` | `approval_sheet` | Лист согласования |
| `order_purchase.docx` | `order_purchase` | Приказ о закупке |

Можно загрузить свой шаблон для конкретной субсидии — он будет использоваться вместо глобального.
Путь: `templates/subsidies/{subsidy_id}/{doc_type}.docx`

## Циклы и таблицы

### Таблица позиций закупки

Используйте в строке таблицы Word:

```
{% for item in items %}
{{ item.num }}         — номер строки (1, 2, 3...)
{{ item.name }}        — наименование товара/услуги
{{ item.description }} — описание (из карточки продукта)
{{ item.type }}        — тип (товар/услуга)
{{ item.quantity }}    — количество
{{ item.unit }}        — единица измерения (шт., компл.)
{{ item.unit_price }}  — цена за единицу (130 000,00 ₽)
{{ item.total_price }} — сумма строки (130 000,00 ₽)
{{ item.photo }}       — фото товара (картинка)
{% endfor %}
```

Дополнительно: `{{ items_count }}` — общее количество позиций, `{{ item_names }}` — перечисление названий через запятую.

### Таблица согласующих

```
{% for a in approvers %}
{{ a.num }} | {{ a.role_name }} | {{ a.full_name }} | {{ a.signature_img }} | {{ a.decided_date }}
{% endfor %}
```

## Частые ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| «Ошибка генерации документа» | Русский текст внутри `{{ }}` | Вынести текст за скобки: `{{ contract_date }} г.` |
| Переменная не подставляется | Word разбил текст на фрагменты | Удалить переменную и набрать заново одним блоком |
| Пустое значение | Поле не заполнено в закупке | Заполнить поле в карточке закупки |
| Фото не появляется | Нет фото у продукта | Загрузить фото в карточку продукта |

**Совет:** если переменная не работает, откройте файл, удалите весь текст `{{ ... }}` и наберите заново — Word иногда вставляет невидимое форматирование внутрь скобок.
