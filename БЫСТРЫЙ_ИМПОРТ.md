# Быстрый импорт данных из Google Sheets файла

## Простой способ импорта через GUI

### Шаг 1: Добавьте скрипт импорта

1. Откройте ваш файл Google Sheets с базой данных
2. Откройте **Расширения → Apps Script**
3. Добавьте в файл `Code.gs` содержимое из `СКРИПТ_ИМПОРТА_С_GUI.gs`
4. Сохраните проект (Ctrl+S)
5. Обновите страницу Google Sheets (F5)

### Шаг 2: Запустите импорт через меню

1. В Google Sheets появится новое меню **"Импорт данных"**
2. Нажмите **Импорт данных → Импорт из Google Sheets файла**
3. Откроется диалоговое окно со списком доступных файлов

### Шаг 3: Выберите файл для импорта

1. В диалоговом окне вы увидите список файлов Google Sheets
2. Файлы с названием "Патриотика" будут показаны первыми
3. Используйте поиск для быстрого нахождения файла
4. Кликните на нужный файл для выбора
5. Нажмите кнопку **"Импортировать"**

### Шаг 4: Дождитесь завершения импорта

1. Скрипт автоматически найдет нужные листы в выбранном файле
2. Импортирует данные в справочники
3. Покажет результаты импорта в диалоговом окне
4. Диалог закроется автоматически через 3 секунды

### Альтернатива: Импорт из текущего файла

Если данные находятся в том же файле, где создается база данных:

1. Нажмите **Импорт данных → Импорт из текущего файла**
2. Данные будут импортированы из того же файла

### Шаг 5: Проверьте результаты

Вернитесь в Google Sheets и проверьте листы:

- **Субсидии** - должны быть заполнены
- **Категории_из_ФЭО** - должны быть заполнены
- **Категории_из_приложения** - должны быть заполнены
- **Контрагенты** - должны быть заполнены

## Что импортируется автоматически

### Из листа "GoodsService":
- ✅ **Субсидии** - уникальные значения из столбца с субсидиями
- ✅ **Контрагенты** - уникальные контрагенты из столбца с контрагентами

### Из отдельных листов:
- ✅ **Категории_из_ФЭО** - весь лист "Категории_из_ФЭО"
- ✅ **Категории_из_приложения** - весь лист "Категории_из_приложения"

## Устранение проблем

### Проблема: Меню "Импорт данных" не появилось

**Решение:**
1. Убедитесь, что скрипт сохранен
2. Обновите страницу Google Sheets (F5)
3. Если меню все еще не появилось, откройте **Расширения → Apps Script** и запустите функцию `onOpen()` вручную

### Проблема: Файл не найден в списке

**Решение:**
- Скрипт ищет файлы с названием "Патриотика"
- Если файл называется по-другому, используйте поиск в диалоговом окне
- Убедитесь, что у вас есть доступ к файлу
- Файл должен быть в формате Google Sheets (не Excel)

### Проблема: Данные не импортируются

**Решение:**
1. Откройте **Вид → Логи выполнения** в Apps Script
2. Проверьте сообщения об ошибках
3. Убедитесь, что листы в файле называются правильно:
   - `GoodsService` (или похожее)
   - `Категории_из_ФЭО` (или похожее)
   - `Категории_из_приложения` (или похожее)

### Проблема: Неправильные названия столбцов

**Решение:**
Скрипт автоматически ищет столбцы по ключевым словам:
- Субсидии: "субсидия", "ведомство", "направление"
- Контрагенты: "контрагент", "поставщик", "исполнитель"

Если столбцы называются по-другому, проверьте логи и при необходимости измените ключевые слова в скрипте.

## Преимущества GUI импорта

- ✅ Не нужно знать ID файла
- ✅ Визуальный выбор файла из списка
- ✅ Поиск файлов по названию
- ✅ Показ результатов импорта
- ✅ Работает напрямую с Google Sheets файлами
- ✅ Не требует загрузки файлов на диск
