**GET /api/chat/rooms** — список комнат текущего пользователя:
- Запрос: SELECT ChatRoom WHERE id IN (SELECT room_id FROM chat_participants WHERE user_id = current_user.id)
- Для каждой комнаты: последнее сообщение (MAX id), unread_count через _get_room_unread
- Возвращает список RoomOut, сортировка по последнему сообщению desc

**POST /api/chat/rooms/direct** — get-or-create 1-on-1 чат:
- Body: `{"target_user_id": int}`
- Проверить что target_user принадлежит той же org_id (CHAT-05)
- Найти существующую комнату: SELECT room_id FROM chat_participants WHERE user_id IN (current_user.id, target_user_id) GROUP BY room_id HAVING COUNT(*) = 2 AND room WHERE is_group=False
- Если не найдена — создать новую ChatRoom(is_group=False, org_id=current_user.org_id) + 2 ChatParticipant
- Вернуть RoomOut

**POST /api/chat/rooms** — создать групповой чат:
- Body: `{"name": str, "participant_ids": list[int]}`
- Проверить что все participant_ids принадлежат той же org_id
- Создать ChatRoom(is_group=True, name=name, org_id=...) + ChatParticipant для creator + все из participant_ids
- Вернуть RoomOut

**GET /api/chat/rooms/{room_id}/messages** — история сообщений:
- Query params: before_id: Optional[int] = None, limit: int = 50
- Проверить что current_user участник комнаты (403 если нет)
- Keyset pagination: WHERE room_id=room_id [AND id < before_id] ORDER BY id DESC LIMIT limit
- Вернуть list[MessageOut] в хронологическом порядке (reversed)
- Обогатить sender_name из таблицы users

**POST /api/chat/rooms/{room_id}/messages** — отправить сообщение (текст или файл):
- Form: content: Optional[str] = Form(None), file: Optional[UploadFile] = File(None)
- Проверить участие current_user в комнате
- Если file: проверить MIME, размер, сохранить в /app/uploads/chat/{room_id}/{uuid}_{filename}
- Создать ChatMessage в БД
- Push WS события всем участникам через manager.send_to_users:
  `{"type": "message", "room_id": room_id, "message": {...MessageOut dict...}}`
- После push обновить unread_count для каждого участника и отправить им WS `{"type": "unread_count", "total_unread": N}`
- Вернуть MessageOut

**POST /api/chat/rooms/{room_id}/read** — отметить прочитанным:
- Проверить участие
- Получить MAX(id) сообщений в комнате
- UPSERT message_reads: INSERT OR UPDATE SET last_read_message_id = max_id WHERE room_id=X, user_id=Y
  Использовать `from sqlalchemy.dialects.postgresql import insert as pg_insert` и `on_conflict_do_update`
- Push WS `{"type": "read", "room_id": room_id, "user_id": current_user.id}` всем участникам
- Push WS `{"type": "unread_count", "total_unread": N}` текущему пользователю (все его соединения)
- Вернуть `{"ok": True}`

**GET /api/chat/staff** — список персонала для нового чата:
- WHERE User.org_id == current_user.org_id AND User.id != current_user.id
- Возвращает list[{"id", "full_name", "username", "avatar", "department", "position"}]

**GET /api/chat/rooms/{room_id}/files/{msg_id}** — скачать файл:
- Проверить участие current_user
- Получить ChatMessage по msg_id, проверить room_id совпадает
- Вернуть FileResponse(message.file_path, filename=message.file_name, media_type=message.file_mime)
