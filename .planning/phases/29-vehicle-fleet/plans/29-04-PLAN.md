## Risks / Gotchas
- **FastAPI routing ordering (Gotcha 2026-04-20):** sub-routers (vehicle_attachments etc.) НЕЛЬЗЯ регистрировать ПЕРЕД vehicles.router. Их prefix = `/api/vehicles/{vehicle_id}/attachments` — FastAPI матчит первый соответствующий route, и если `vehicle.router` catch-all `/api/vehicles/{vehicle_id:int}` стоит ПЕРЕД, то `/api/vehicles/123/attachments` сначала уйдёт в catch-all → 422. Решение: либо (a) регистрировать sub-routers ПЕРЕД vehicles, либо (b) сделать sub-routers с prefix `/api/vehicle-attachments`, `/api/vehicle-repairs` etc. — **выбираем (b) для чистоты, см. план 29-05**.
- **_coerce_patch_value:** скопировать целиком из `purchases.py`, переменные _DATE_FIELDS заменить на свои. Тестировать что `''` → None для `vin`, `insurance_until`.
- **flag_modified(vehicle, 'props'):** обязательно если PATCH трогает `props` JSONB. Gotcha 2026-05-13.
- **History hook должен срабатывать ДО `setattr`:** snapshot old_val в локальной переменной.
- **dict-detail HTTPException:** custom handler в `__init__.py:237-249` пакует dict в `{code, message, details, correlation_id}`. Можно использовать `raise HTTPException(409, detail={"code": "DUPLICATE_PLATE", "message": "...", "plate": plate})`.
- **`current_odometer_km` не редактируется напрямую** — обновляется через `vehicle_odometer.py` POST endpoint (план 29-07). PATCH игнорирует это поле даже если пришло в body.
