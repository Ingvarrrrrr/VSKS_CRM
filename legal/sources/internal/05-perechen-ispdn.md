# {{doc.title}}

## 1. Состав информационных систем персональных данных

Оператор эксплуатирует одну информационную систему персональных
данных — систему {{site.product_full_name}} ({{site.url}}),
далее ИСПДн «{{site.product_name}}».

| Компонент | Назначение | Место размещения |
|---|---|---|
| База данных PostgreSQL | основное хранилище персональных данных: учётные записи, данные контрагентов, документы, координаты местоположения, журналы изменений | сервер {{hosting.provider}}, {{hosting.country}} |
| Серверное приложение (backend) | обработка запросов, применение правил доступа и ролевой модели, формирование документов | тот же сервер, {{hosting.country}} |
| Веб-интерфейс (frontend) | клиентское приложение для работы пользователей через браузер | раздаётся тем же сервером через {{site.url}}, персональные данные на стороне клиента не хранятся постоянно |
| Резервные копии базы данных | восстановление данных при сбое или ошибке | инфраструктура {{hosting.provider}}, {{hosting.country}}, доступ ограничен ответственным за организацию обработки персональных данных |

Файловые вложения, содержащие персональные данные (изображение
подписи, фотография профиля, скан водительского удостоверения),
хранятся внутри той же базы данных PostgreSQL как часть записи
пользователя, отдельное файловое хранилище (в том числе внешние
объектные хранилища) для персональных данных не используется.

## 2. Уровень защищённости

Уровень защищённости персональных данных, обрабатываемых в ИСПДн
«{{site.product_name}}», определён Актом определения уровня
защищённости персональных данных. Технические и организационные меры
защиты, применяемые для достижения установленного уровня
защищённости, определены Правилами доступа к персональным данным
в информационной системе и Моделью угроз безопасности персональных
данных.

## 3. Место физического размещения и доступ

3.1. Сервер, на котором размещена ИСПДн «{{site.product_name}}»,
находится на инфраструктуре {{hosting.provider}} на территории
{{hosting.country}} ({{hosting.note}}).

3.2. Физический доступ к серверному оборудованию Оператор
самостоятельно не осуществляет и обеспечивается силами
{{hosting.provider}} на условиях заключённого с ним договора.
Договор с {{hosting.provider}} содержит условие о конфиденциальности
и обязанность обеспечить сохранность размещаемых данных.

3.3. Удалённый административный доступ к серверу (по протоколу SSH)
и доступ к базе данных предоставлен исключительно ответственному
за организацию обработки персональных данных — {{responsible.fio}}
({{responsible.email}}). Доступ защищён ключевой парой и парольной
аутентификацией в соответствии с Правилами доступа к персональным
данным в информационной системе.

3.4. Периметр сервера защищён межсетевым экраном: наружу открыты
только порты, необходимые для работы веб-приложения по защищённому
протоколу (HTTPS) и административного доступа по ключу; порты базы
данных и служебных сервисов для внешних подключений закрыты.

## 4. Резервное копирование

Резервные копии базы данных ИСПДн «{{site.product_name}}» создаются
регулярно в автоматическом режиме и хранятся на той же
инфраструктуре, на территории Российской Федерации. Доступ
к резервным копиям ограничен кругом лиц, указанным в пункте 3.3.
Риски, связанные с резервным копированием (в том числе утрата
или неправомерный доступ к резервной копии), учтены в Модели угроз
безопасности персональных данных.

## 5. Пересмотр

Настоящий Перечень пересматривается при изменении состава
информационных систем, смене хостинг-провайдера или места размещения
серверов, а также не реже одного раза в год.
