## Goal
Endpoint для UI-импорта Excel: пользователь загружает свой xlsx (с тем же форматом, что Голичкова или совместимым), backend парсит, возвращает preview + список «unmapped регионов» (из колонки «У кого в эксплуатации» которые не сопоставлены ни с одной Organization). После того как UI присылает mapping `{region_text → org_id}`, backend применяет ON CONFLICT INSERT.

## Tasks
1. Создать `vehicles_import.py` с `router = APIRouter(prefix="/api/vehicles-import", tags=["vehicles"])`.
2. **POST `/api/vehicles-import/preview`** — multipart upload xlsx. `require_action('vehicle.import')`. Body: `file: UploadFile`. Сохранить в /tmp как временный файл (с UUID имени), вернуть **preview**:
   ```python
   {
       "session_id": "<uuid>",  # для следующего commit запроса
       "tmp_path": "/tmp/import_<uuid>.xlsx",  # внутреннее
       "rows_total": 51,
       "rows_valid": 48,  # с plate
       "rows_invalid": 3,
       "unmapped_regions": [
           {"raw_text": "Иркутская область", "occurrences": 5},
           {"raw_text": "Камчатский край", "occurrences": 2},
           ...
       ],
       "matched_orgs": [
           {"raw_text": "ВСКС", "org_id": 1, "org_name": "ВСКС"},
           ...
       ],
       "preview_items": [  # первые 10 строк для UI
           {"plate": "А001АА77", "brand_model": "Митсубиши Делика", "owner_text": "ВСКС", "assigned_text": "Москва", ...},
           ...
       ],
       "warnings": ["Строка 23: plate отсутствует, пропущена", ...]
   }
   ```
   Логика: парсинг через `openpyxl` (как в `vehicles_seed.py`), для каждой строки попытаться lookup org_id по тексту owner и assigned. Накопить unmapped regions.
3. **POST `/api/vehicles-import/commit`** — после preview UI присылает финальный mapping. Body:
   ```python
   {
       "session_id": "<uuid>",
       "region_mapping": {"Иркутская область": 12, "Камчатский край": 14, ...},
       "default_owner_org_id": 1,  # ВСКС
       "conflict_strategy": "skip" | "update"  # skip = ON CONFLICT DO NOTHING; update = ON CONFLICT DO UPDATE SET ...
   }
   ```
   Восстановить tmp файл по `tmp_path` из session_id (хранить mapping `session_id → tmp_path` в Python in-memory dict с TTL 30 мин). Для каждой строки: применить region_mapping для `assigned_text`; если plate уже есть в БД и strategy=update → UPDATE; иначе → INSERT ON CONFLICT DO NOTHING. Удалить tmp файл после commit. Вернуть `{inserted: N, updated: M, skipped: K, errors: [...]}`.
4. **GET `/api/vehicles-import/preview/{session_id}`** — re-fetch preview (для случая когда UI потерял состояние).
5. Хранилище session_id → данные в Python: `_IMPORT_SESSIONS: dict[str, dict] = {}` с очисткой старых (TTL 30 мин). Каждый запись содержит `{tmp_path, created_at, parsed_rows}`.
6. **Visibility:** require_action('vehicle.import') = admin/org_admin only (per D-05). Не нужна доп. visibility — импорт идёт от admin'а, владелец машины определяется через owner_org_id в body.
7. Helper `_cleanup_old_sessions()` — вызывать в начале каждого preview/commit; удалять sessions старше 30 мин (вместе с tmp файлами).
8. В `__init__.py` `include_router(vehicles_import.router)`.
9. Commit message: `feat(29-12): vehicles_import — UI preview + region→org mapping + commit`

## Risks / Gotchas
- **In-memory session store:** при restart backend сессии теряются. OK для UX 30-min — после рестарта юзер просто загружает заново. Не writing в БД отдельной таблицы — overhead не оправдан для редкой операции.
- **tmp файлы на /tmp:** на проде это inside Docker container — удалится при restart. Все равно очищать после commit.
- **Recursive openpyxl parse:** одинаковый код в seed и в import — рассмотреть вынесение `_parse_xlsx_row()` в shared service. **Решение:** скопировать в import_router (DRY можно сделать в отдельной фазе) либо импортировать `_parse_xlsx_row` из `vehicles_seed.py` (если вынесли).
- **session_id security:** UUID4 — достаточно. Не нужны JWT-bound sessions.
- **dict-detail для ошибок** (Lesson 2026-05-04).
