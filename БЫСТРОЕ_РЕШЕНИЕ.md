# Быстрое решение проблем

## Проблема: Меню не появляется

### Решение за 30 секунд:

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `createMenu` (или `testAndFix`)
3. Нажмите **Выполнить** (▶)
4. Вернитесь в Google Sheets
5. Меню должно появиться!

## Проблема: Данные не импортируются

### Решение 1: Импорт из текущего файла

Если файл "Патриотика" находится в том же файле Google Sheets:

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `quickImportFromCurrentFile`
3. Нажмите **Выполнить** (▶)
4. Данные будут импортированы автоматически

### Решение 2: Ручной импорт

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `importFromCurrentFile`
3. Нажмите **Выполнить** (▶)

## Диагностика системы

Для проверки всех компонентов:

1. Откройте **Расширения → Apps Script**
2. Найдите функцию `testAndFix`
3. Нажмите **Выполнить** (▶)
4. Появится окно с диагностикой:
   - Статус меню
   - Список созданных листов
   - Найденные файлы для импорта
   - Рекомендации по исправлению

## Пошаговая инструкция

### Шаг 1: Обновите скрипт

1. Откройте файл `ПОЛНЫЙ_СКРИПТ_БАЗЫ_ДАННЫХ.gs`
2. Скопируйте ВЕСЬ код
3. В Apps Script замените весь код на новый
4. Сохраните (Ctrl+S)

### Шаг 2: Создайте структуру (если еще не создана)

1. Выберите функцию `createDatabaseStructure`
2. Нажмите **Выполнить** (▶)
3. Должны создаться 10 листов

### Шаг 3: Создайте меню

1. Выберите функцию `createMenu`
2. Нажмите **Выполнить** (▶)
3. Вернитесь в Google Sheets
4. Меню должно появиться

### Шаг 4: Импортируйте данные

**Вариант А: Через меню (если появилось)**
1. Нажмите **📥 Импорт данных → 📂 Импорт из Google Sheets файла**
2. Выберите файл "Патриотика"
3. Нажмите **Импортировать**

**Вариант Б: Вручную (если меню не работает)**
1. Откройте **Расширения → Apps Script**
2. Выберите функцию `quickImportFromCurrentFile`
3. Нажмите **Выполнить** (▶)

## Проверка результатов

После импорта проверьте листы:

- **Субсидии** - должны быть заполнены данными
- **Категории_из_ФЭО** - должны быть заполнены данными
- **Категории_из_приложения** - должны быть заполнены данными
- **Контрагенты** - должны быть заполнены данными

## Если ничего не помогает

1. Запустите функцию `testAndFix()` - она покажет все проблемы
2. Проверьте логи выполнения в Apps Script (Вид → Логи выполнения)
3. Убедитесь, что используете последнюю версию скрипта
4. Попробуйте создать новый файл Google Sheets и скопировать туда скрипт заново
