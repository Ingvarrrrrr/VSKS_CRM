# {{doc.title}}

Журнал ведётся ответственным за организацию обработки персональных
данных и предназначен для учёта обращений и запросов субъектов
персональных данных (или их представителей), а также запросов
уполномоченного органа по защите прав субъектов персональных данных,
связанных с обработкой персональных данных в
{{operator.full_name}}.

## Форма журнала

| № | Дата поступления обращения | От кого поступило (ФИО субъекта / наименование органа) | Способ поступления | Суть обращения | Срок ответа | Дата ответа | Содержание ответа / принятое решение | Кто исполнил |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

## Пояснения к заполнению

1. **Способ поступления** — электронная почта {{responsible.email}},
   письменное обращение по почтовому адресу Оператора, устное
   обращение с последующей письменной фиксацией.

2. **Суть обращения** — краткое описание требования субъекта:
   предоставление информации об обработке его персональных данных;
   уточнение персональных данных; отзыв согласия на обработку;
   требование прекратить обработку и уничтожить персональные данные;
   иное.

3. **Срок ответа** заполняется исходя из существа обращения:

   | Вид обращения | Срок |
   |---|---|
   | Предоставление сведений о наличии и составе персональных данных | {{deadlines_working_days.info_request}} рабочих дней, с возможным продлением на {{deadlines_working_days.info_request_extension}} рабочих дней |
   | Уточнение персональных данных | {{deadlines_working_days.correction}} рабочих дней |
   | Уничтожение персональных данных при отзыве согласия | {{deadlines_working_days.destruction_on_withdrawal}} рабочих дней |
   | Прекращение неправомерной обработки персональных данных | {{deadlines_working_days.stop_unlawful_processing}} рабочих дней |

4. Повторное обращение того же субъекта по тому же вопросу,
   поступившее ранее чем через
   {{deadlines_working_days.repeat_request_cooldown_days}} дней
   после получения им ответа на предыдущее обращение и не содержащее
   новых доводов, может быть оставлено без повторного рассмотрения
   по существу с направлением субъекту мотивированного ответа
   со ссылкой на ранее данный ответ.

5. Каждая запись в Журнале хранится ответственным за организацию
   обработки персональных данных как минимум до истечения срока
   хранения персональных данных субъекта, обратившегося
   с соответствующим обращением, указанного в Перечне обрабатываемых
   персональных данных.

6. Запросы уполномоченного органа по защите прав субъектов
   персональных данных регистрируются в этом же Журнале с пометкой
   «Роскомнадзор» в графе «От кого поступило».
